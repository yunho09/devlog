# 2026-07-08

## 요약
사용자 로그아웃 UX를 개선하고 로컬 개발 환경의 Husky 설정을 보완한 작업입니다. 기존 사이드바 하단 영역을 클릭하여 로그아웃하던 비직관적인 방식을 제거하고, 홈 화면에 전용 로그아웃 버튼과 로직을 추가했습니다. 또한, 로컬 환경에서 Bun 패키지 매니저를 안정적으로 찾아 Git 훅을 수행할 수 있도록 Husky 스크립트를 수정했습니다.

## 변경 내용
- **로그아웃 기능 개선**
  - 홈 화면(`home.tsx`)에 로그아웃 버튼 UI를 추가하고 로그아웃 비즈니스 로직을 연결했습니다.
  - 사이드바 하단(`sidebar-footer.tsx`)의 사용자 정보 영역 클릭 시 수행되던 로그아웃 이벤트를 제거했습니다.
  - 클릭 및 호버 효과가 필요 없어진 사이드바 하단의 스타일링 코드를 삭제했습니다.
- **Husky 설정 수정**
  - `.husky/pre-commit` 및 `.husky/pre-push` 스크립트에서 Bun 실행 파일을 보다 안정적으로 찾을 수 있도록 개선했습니다.
  - 로컬 환경에 Bun이 없을 경우 명확한 안내 메시지를 출력하고 작업을 안전하게 중단하도록 예외 처리를 적용했습니다.

## 의도
기존에는 사이드바 하단 사용자 영역에 숨겨져 있던 로그아웃 기능이 직관적이지 못해 오작동을 유발할 가능성이 있었습니다. 이를 해결하기 위해 홈 화면에 명시적인 로그아웃 버튼을 마련하여 사용성을 개선하고자 했습니다. 

또한, 다양한 팀원의 로컬 개발 환경에서 Bun 패키지 매니저 경로 불일치 등으로 인해 Git 훅(Husky)이 실패하는 문제를 방지하여 개발자 경험(DX)을 안정화하고자 했습니다.
