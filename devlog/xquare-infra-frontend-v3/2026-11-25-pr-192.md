# 2026-11-25

## 요약
PVE Container(CT) 및 Virtual Machine(VM) 생성 페이지의 UI 퍼블리싱을 진행했습니다. API 연동에 앞서 목업 데이터를 기반으로 CT와 VM 선택에 따른 동적 폼 구성, 실시간 요약 패널 및 필수 항목 유효성 검사 로직을 구현했습니다. 이를 통해 사용자가 입력 상태를 한눈에 확인하며 인프라 자원을 생성할 수 있는 흐름을 완성했습니다.

## 변경 내용
- `/container/create` 라우트 등록, 브레드크럼 및 페이지 헤더 구성
- CT / VM 카드 선택에 따라 폼 입력 항목, 기본값 안내 박스, 요약 패널, 생성 버튼 문구가 동적으로 변경되도록 구현
- 기본 정보(노드 셀렉터, 자동 생성 ID 안내, Hostname/VM Name), OS(템플릿/ISO 패키지), 리소스(CPU, Memory, Swap/CPU 타입), 스토리지 및 네트워크 설정 폼 추가
- 입력값 변화를 실시간 반영하는 LXC/KVM 생성 요약 패널 컴포넌트(`CreateSummary.tsx`) 추가
- 생성 폼 옵션 목업 데이터(`options.ts`) 및 폼 컨트롤 컴포넌트(`FormControls.tsx`) 분리
- 필수 입력 항목 충족 시 생성 버튼 활성화 로직 및 완료/취소 시 목록(`/container`) 이동 처리

## 의도
Proxmox VE 기반 자원 생성 과정의 사용자 경험을 피그마 시안에 맞춰 프론트엔드 UI로 구현하기 위해 진행되었습니다. API 연동 이전에 mock 데이터를 기반으로 폼 입력 및 유효성 검증, 요약 패널 간의 상태 연동 인터페이스를 정립하고자 했습니다.
