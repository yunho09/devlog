# 2026-07-21

## 요약
공지사항 상세 페이지에서 기존 게시글을 수정 및 삭제할 수 있는 기능을 추가했습니다. 기존 첨부파일의 상태 관리와 용량 검증 기능이 보완되었으며, 저장되지 않은 변경사항이 있을 때 페이지 이탈을 방지하는 안전장치를 마련했습니다. 또한 중복 요청 방지, 예외 처리, 삭제 확인 대화상자의 웹 접근성 개선 및 E2E 테스트 추가가 포함되었습니다.

## 변경 내용
- **공지사항 수정/삭제 및 예외 처리**: 공지사항 상세 페이지에서 편집 및 삭제 기능을 추가하였으며, 존재하지 않는 공지에 접근 시 안내 화면 및 목록 이동 링크를 표시합니다.
- **폼 및 첨부파일 관리 강화**: `NoticeForm`과 `NoticeAttachmentField`를 확장하여 기존 첨부파일을 조회하고 추가/삭제하는 상태 관리 로직을 보강했으며, 파일 용량 검증과 다운로드 기능을 개선했습니다.
- **사용자 경험 개선**: 데이터 수정 중 저장하지 않고 페이지를 나갈 때 경고창을 띄우고, 유효성 검사 실패 시 입력란으로 포커스를 강제 이동시킵니다.
- **접근성 및 중복 방지**: 삭제 확인 다이얼로그(`DeleteConfirmationDialog`)의 키보드 포커싱 접근성을 수정하였고, 저장/삭제 시 중복 요청이 가지 않도록 제어했습니다.
- **테스트 추가**: 시나리오 기반 승인 테스트 명세(`notice-edit.spec.md`, `notice-edit.scenario-draft.md`) 및 Playwright를 활용한 E2E 테스트 코드를 새로 작성했습니다.

## 의도
사용자가 작성한 공지사항을 안전하게 편집하고 삭제할 수 있는 관리 기능을 완성하기 위함입니다. 특히 첨부파일의 동적 변경을 안전하게 처리하고, 사용자의 실수로 인한 데이터 유실(페이지 이탈)을 막는 등의 디테일한 UX 보완을 통해 애플리케이션의 완성도를 높이고자 했습니다.
