# 2026-07-21

## 요약
공지사항 등록을 위한 생성 페이지의 퍼블리싱 및 핵심 기능 구현을 완료했습니다. 작성 중 이탈 시 경고 모달 제공, 대용량 첨부파일 예외 처리 등의 UX 개선 작업과 함께 목록 화면의 검색, 정렬, 페이지네이션 기능을 추가했습니다. 명세서(spec) 작성과 E2E 테스트 코드를 보강하여 기능의 동작 안정성을 확보했습니다.

## 변경 내용
- **공지사항 생성 폼 구현**: 제목, 내용, 분류, 대상 팀 지정, 파일 첨부 기능을 포함한 `NoticeForm` 추가 및 중복 제출 방지 처리.
- **이탈 방지 UX 도입**: 공지사항 작성 도중 페이지를 벗어나려고 할 때 띄워주는 이탈 확인 모달(`LeaveConfirmationDialog`) 구현 및 키보드 접근성/포커스 수정.
- **첨부파일 유효성 검사**: 파일 첨부 시 용량이 초과된 파일만 영리하게 제외하고 업로드되도록 로직 수정 (`f93d801`).
- **목록 탐색 기능 강화**: 공용 데이터 테이블(`DataTable`)에 검색 바, 페이지네이션을 추가하고 정렬(sort)과 검색(search) 로직을 분리.
- **테스트 및 스펙 명세 추가**: 공지사항 생성에 대한 요구사항 문서(`notice-create.spec.md`) 작성 및 생성/필터링 동작을 검증하는 E2E 테스트 코드 추가.

## 의도
사용자가 공지사항을 작성하는 과정에서 의도치 않게 데이터를 잃어버리지 않도록 방어하는 안전장치를 마련하고, 파일 업로드 시 발생할 수 있는 에러 상황에 대한 UX를 다듬고자 했습니다. 또한 목록 내 데이터가 누적되었을 때 사용자가 정보를 빠르게 찾을 수 있도록 검색, 필터, 정렬 기능을 대폭 확장했습니다.
