# 2026-07-06

## 요약
ToyVillage-App-FE 프로젝트의 사이드바 구현을 이어서 보완한 PR이다. 사이드바 UI와 토글 버튼, 메뉴 데이터, 아이콘 자산을 포함한 기본 구조를 유지하면서 초기 포커스 오류를 수정했고, PR 본문에는 스크롤 잠금과 닫기 동작, 메뉴 선택 시 이동 흐름까지 정리되어 있다. 이전 사이드바 작업보다 사용자 상호작용 안정성에 초점이 더해진 변경이다.

## 변경 내용
- **사이드바 퍼블리싱 추가**: 공지 관련 화면에서 사용할 사이드바, 토글 버튼, 오버레이, 프로필 영역, 메뉴 활성 상태를 구성함.
- **상호작용 보완**: 사이드바가 열릴 때 본문 스크롤을 잠그고, `Esc` 키, 닫기 버튼, 배경 클릭으로 닫히는 흐름을 반영함.
- **메뉴 이동 흐름 정리**: 메뉴 선택 시 관련 화면으로 이동하고 사이드바가 자동으로 닫히는 동작을 포함함.
- **초기 포커스 오류 수정**: `fix: 초기 포커스 오류 수정` 커밋을 통해 사이드바 표시 시 포커스 처리 문제를 보완함.
- **검증 자료 유지**: 사이드바 하네스 명세, approval 파일, E2E 테스트를 포함해 구현 결과를 검증할 수 있게 함.

## 의도
공지 화면군에서 공통으로 사용할 내비게이션을 만들고, 모바일과 데스크톱 모두에서 열기/닫기/메뉴 이동이 안정적으로 동작하도록 다듬으려는 의도로 보인다. 특히 초기 포커스 오류 수정과 닫기 인터랙션 보완은 사이드바가 단순한 정적 퍼블리싱을 넘어 실제 사용 흐름에서 불편하지 않게 동작하도록 맞춘 변경으로 해석된다.
