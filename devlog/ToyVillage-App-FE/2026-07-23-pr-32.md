# 2026-07-23

## 요약
공지사항 작성 및 수정 화면의 분류(카테고리) UI 동작을 개선하고 관련 E2E 테스트를 보완한 작업입니다. 팀의 유무에 따라 '전체' 분류가 동적으로 표시되도록 상태 로직을 수정하고 선택 상태를 올바르게 유지하도록 개선했습니다. 이에 대응하여 공지 작성 및 수정 시나리오에 대한 E2E 테스트를 강화했습니다.

## 변경 내용
- **UI 및 상태 로직 개선**:
  - 공지 작성/수정 화면(`NoticeForm.tsx`)에서 선택된 팀이 없을 경우 초기값을 '전체'로 표시하도록 수정했습니다.
  - 첫 팀을 추가하면 '전체' 카테고리가 자동으로 사라지고, 추가된 팀을 모두 삭제하면 다시 '전체' 상태로 돌아가도록 수정했습니다.
  - 팀의 추가 및 삭제 이후에도 선택된 분류 상태가 올바르게 동기화되도록 유지했습니다.
  - 공지 작성/수정 화면에서 '팀 추가' 버튼의 노출 및 표시 상태를 상황에 맞게 조정했습니다.
- **테스트 코드 보강**:
  - 팀 추가 및 삭제, 카테고리 선택 상태 변화, 키보드 이동, 첨부파일 관련 시나리오를 검증하기 위한 E2E 테스트 코드를 대폭 보강했습니다.

## 의도
사용자가 공지사항의 수신 대상을 지정할 때 보다 직관적이고 오류 없는 UI 경험을 제공하기 위함입니다. 팀 지정 여부에 따라 '전체' 공지와 '특정 팀' 공지 상태가 유기적으로 전환되도록 유도하여 상태 오염을 방지하고, 이를 견고히 검증하기 위해 E2E 테스트 시나리오를 추가했습니다.
