### 쓰는 법 (냉장고 화면에서)

```tsx
<IngredientEditModal
  ingredient={selectedIngredient} // null이면 닫힘
  onClose={() => setSelectedIngredient(null)}
  onSave={(id, { name, icon, expiresAt }) => updateIngredient(id, ...)} // Promise, 실패 시 throw
  onDelete={(id) => deleteIngredient(id)} // Promise, 실패 시 throw
/>
```

성공하면 모달이 스스로 `onClose`를 부른다. 실패해도 목록은 그대로라서 되돌릴 화면 상태가 없다.

## 변경 이유

- Sprint 1의 재료 수정 모달 작업이다. 디자인은 Bium-v1 `FoodModal`을 따르고 TypeScript로 새로 작성했다.

  - 아이콘 글자 수는 `Intl.Segmenter`로 센다. Bium-v1의 `maxLength={2}`는 국기나 피부색 이모지를 넣으면 잘렸다.
- 장본 음식 유통기한 수정과 "장본 음식으로 이동"은 도감·드래그 앤 드롭 작업에서 다룬다.
