## 요약
도감에서 식재료를 냉장고에 추가할 때 기본 보관 위치가 항상 냉장실(`"FRIDGE"`)로 고정되던 문제를 해결했습니다. 백엔드 API 응답 변경사항에 맞춰 `CatalogIngredient` 타입에 `defaultStorage` 필드를 추가했습니다. 모달 열림 시 `ingredient.defaultStorage` 값을 사용하고, 해당 값이 `null`일 경우 기존과 동일하게 냉장실을 기본값으로 처리하도록 수정했습니다.

## 변경 내용
- `CatalogIngredient` 타입 정의에 `defaultStorage: StorageType | null` 필드 추가
- `CatalogIngredientCreateRequest` 요청 타입에는 `defaultStorage`를 제외하여 생성 요청 본문 구조 유지
- `FridgeAddModal.tsx`에서 초기 보관 위치 설정 시 `ingredient.defaultStorage`를 사용하고, `null`일 경우 `"FRIDGE"`를 기본값으로 사용하도록 로직 수정

## 의도
식재료 도감에 등록된 항목마다 적절한 기본 보관 위치(예: 냉동, 실온 등)가 다를 수 있음에도 불구하고, 이전에는 모달 초기 위치가 항상 냉장실로 고정되어 있었습니다. 백엔드에서 도감 응답에 기본 보관 위치 데이터를 추가함(bium2026/bium-be#80)에 따라, 프론트엔드에서도 해당 데이터를 활용해 사용자 편의성을 향상시키고자 변경했습니다.
