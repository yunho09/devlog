## 요약
구매 달력에서 고른 날짜의 재료들을 장보기 목록에 일괄 추가하는 기능을 구현했습니다. `addShoppingListItems` API를 신설하고 달력 UI에서 재료 담기 버튼 및 결과/에러 메시지 안내 로직을 추가했습니다. 또한 추가된 재료를 목록 상단에 즉시 반영하고 404 에러 시 냉장고 재로드 화면으로 연결되도록 처리했습니다.

## 변경 내용
- `src/api/shoppingList.ts`: `POST /api/fridges/{fridgeId}/shopping-list-items/bulk` 엔드포인트를 호출하는 `addShoppingListItems` API 함수 추가.
- `PurchaseCalendar.tsx`:
  - 선택한 날짜 재료 하단에 "장보기 목록에 담기" 버튼 추가.
  - 성공 및 중복 상태에 따른 안내 문구("N개를 담았어요", "N개를 담았어요. M개는 이미 목록에 있어요", "이미 장보기 목록에 모두 있어요") 출력.
  - 요청 처리 중 버튼 비활성화로 중복 요청 방지 및 400·네트워크 에러 응답 처리.
- `ShoppingListPage.tsx`:
  - 새로 추가된 항목을 장보기 목록 맨 앞에 배치하도록 연동.
  - 냉장고가 조회되지 않는 예외 상황(404 에러) 발생 시 냉장고 다시 불러오기 화면으로 이동 처리.

## 의도
사용자가 다음 구매 날짜 달력에서 필요한 날짜의 재료를 손쉽게 장보기 목록으로 가져올 수 있도록 UX를 개선하기 위한 변경입니다. 중복 요청 방지 및 상세한 결과 메시지 처리를 통해 유저 피드백을 강화하고자 했습니다.
