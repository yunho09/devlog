- PR 본문: ## 내용
장보기 항목 이름을 그 자리에서 고칠 수 있게 했다.

- `ShoppingSection`: 항목마다 빼기 버튼 옆에 "이름 고치기"(연필, `aria-label` 포함) 버튼을 두었다. 누르면 그 항목이 입력칸·저장·취소로 바뀐다. Enter로 저장, Esc·취소로 닫고, 닫으면 고치기 버튼으로 포커스를 돌린다.
- 이름 규칙은 담기 입력칸과 같다(앞뒤 공백 제거 후 1~50자). 이름이 그대로면 요청 없이 닫는다.
- 저장은 서버 응답을 받은 뒤에만 화면 이름을 바꾸고(실패하면 원래 이름 그대로), 요청 중에는 입력칸을 읽기 전용·저장 버튼을 잠가 중복 요청을 막는다. 실패하면 입력칸 아래에 서버 문구(400·연결 오류) 또는 다시 시도 안내를 보여 준다.
- 이미 빠졌거나 그사이 바뀐 항목(404·409)은 체크·빼기처럼 목록을 새로 불러와 안내하고, 냉장고에서 내보내졌으면 냉장고 다시 불러오기 화면으로 보낸다.
- API: `renameShoppingListItem` → `PATCH /api/shopping-list-items/{itemId}/name` (bium-be #113, 머지됨)
- 좁은 화면에서는 입력칸과 버튼이 줄바꿈되게 했다(`flex-wrap`).
