# 2026-11-25

## 요약
다음 구매 날짜 달력 UI(`PurchaseCalendar.tsx`)에 구매 주기가 중복되는 날을 안내하는 '피버타임' 표시 기능을 구현했습니다.
같은 날 구매한 재료들의 구매 주기 최소공배수(LCM)를 기반으로 피버타임 날짜를 계산하며, 365일을 초과하는 주기는 대상에서 제외하도록 처리했습니다.
피버타임 날짜 셀 스타일링, 상단 안내 배너 클릭 시 해당 날짜 이동 기능, 선택 시 상세 재료 안내 및 접근성(`aria-label`)을 함께 추가했습니다.

## 변경 내용
- **달력 내 피버타임 계산 로직 구현 (`PurchaseCalendar.tsx`)**:
  - `lastPurchasedAt`이 동일한 재료 2개 이상을 한 묶음으로 파악하고, 각 재료 `cycleDays`의 최소공배수를 이용해 피버타임 계산.
  - 지나간 피버타임 날짜는 오늘 이후 처음으로 주기가 겹치는 날짜로 자동 갱신.
  - 계산된 최소공배수가 365일을 넘는 경우 장보기 계획 관점에서 제외.
- **달력 UI 및 사용자 인터랙션 추가**:
  - 피버타임 날짜 셀에 `--block-coral` 배경색 및 불꽃 아이콘 적용.
  - 달력 상단에 "다음 피버타임은 N월 D일이에요" 안내 문구 추가 및 클릭 시 해당 월/날짜 선택 연동.
  - 날짜 선택 시 해당 피버타임에 함께 구매할 재료 목록 안내 표시.
  - 접근성 향상을 위해 피버타임 버튼 `aria-label`에 "피버타임" 속성 추가.

## 의도
