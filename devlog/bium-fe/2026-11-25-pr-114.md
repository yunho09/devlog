# 2026-11-25

## 요약
인증 토큰 만료 및 401 응답 발생 시 로그인 화면에서 사용자에게 만료 사실을 안내하는 기능을 추가했습니다. `authStore`에 만료 전용 상태 및 액션을 신설하고, 탭 이동 및 로그인 성공 시 상태가 적절히 해제되도록 처리했습니다. 기존 로그아웃 동작과의 간섭을 피하면서 향상된 사용자 경험을 제공합니다.

## 변경 내용
- `authStore`에 `isExpired` 상태와 `expireAuth`, `dismissExpired` 액션 추가 (`isExpired`는 `partialize` 설정을 통해 localStorage 영속화 대상에서 제외)
- `api/client.ts`에서 401 응답을 받거나 이미 만료된 `expiresAt` 토큰 확인 시 `clearAuth` 대신 `expireAuth` 호출
- `LoginForm`에 만료 상태일 경우 "로그인이 만료됐어요. 다시 로그인해 주세요." 안내 메시지 표시 (회원가입 완료 안내가 있을 경우 기존 안내 메시지 우선 표시)
- `AuthPage`에서 회원가입 탭으로 전환 시 `dismissExpired`로 안내 해제, 로그인 성공(`setAuth`) 또는 수동 로그아웃(`clearAuth`) 시 만료 안내 상태 초기화

## 의도
기존에는 토큰이 401 오류로 인해 삭제될 때 이유를 알려주지 않고 로그인 화면으로 이동시켜 사용자가 강제 로그아웃된 이유를 알 수 없었습니다. 헤더 로그아웃 버튼과의 이벤트 전달 구조를 유지하면서 만료 상태만 따로 구분해 안내하기 위해 새로운 액션과 상태를 도입했습니다.
