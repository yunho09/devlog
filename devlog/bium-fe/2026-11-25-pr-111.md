## 요약
피드 코멘트 작성 폼에서 텍스트를 수정할 때 입력 관련 오류 안내가 자동으로 삭제되도록 개선했습니다. 폼 오류 상태 구조를 `{ message, isInputError }`로 변경하여 단순 입력 오류와 네트워크/서버 요청 실패 오류를 구분했습니다. 이를 통해 공백 제출 시 표시되던 오류 메시지가 입력을 수정해도 계속 남아 있던 문제를 해결했습니다.

## 변경 내용
- `FeedComments` 컴포넌트의 폼 에러 상태 형태를 기존 문자열에서 `{ message, isInputError }` 객체 구조로 변경
- 코멘트 및 추천 음식 입력창의 `onChange` 핸들러에서 `isInputError`가 true인 경우(공백 제출, 서버 400 입력 오류 등)에만 에러 상태를 초기화하도록 수정
- 네트워크 연결 실패나 500 서버 오류 등 재시도가 필요한 안내 메시지는 입력 변경 시 유지되고 다음 제출 때 지워지도록 동작 보존

## 의도
공백 문자로 폼 제출 시 나타난 "코멘트를 입력해 주세요." 메시지가 글자를 고쳐 써도 다음 제출 시점까지 지워지지 않는 UX 불편을 해결하기 위함입니다. 기존 프로젝트 내 `ShoppingAddForm` 및 `TargetRecipeForm`의 오류 처리 패턴과 일치시켜, 사용자가 입력을 수정하면 입력 오류 피드백은 즉시 지워지도록 만들었습니다.
