## 변경 내용
- `FridgeSwitcher.tsx`: 레시피 상세 화면에서 헤더를 통해 다른 냉장고로 바꿀 때, 뒤로 가기로 이전 상세에 진입하지 못하도록 `replace`를 사용하여 `/recipes` 목록으로 리다이렉트 처리.
- `recipeStore.ts`: '만들고 싶은 음식' 생성 요청 상태에 요청 대상 `fridgeId`를 저장하도록 상태 구조 수정.
- `TargetRecipeForm.tsx`: 요청 상태의 `fridgeId`와 현재 활성화된 냉장고 ID를 비교하여, 해당 요청이 진행 중인 냉장고 화면에서만 기다림 및 에러 상자를 노출하고 다른 냉장고에서는 "다른 냉장고 레시피 만드는 중" 안내와 함께 버튼을 비활성화하도록 변경.

## 의도
냉장고 A의 레시피 상세를 열어둔 상태에서 냉장고 B로 스위칭했을 때, 화면에 냉장고 A의 레시피가 남아 요리 완료(재료 차감)나 장보기 목록 연동 시 데이터 불일치가 발생하는 현상을 방지하기 위함입니다. 백엔드 레시피 응답 데이터에 냉장고 ID가 포함되어 있지 않으므로 클라이언트의 냉장고 전환 시점을 감지해 목록으로 이동시키고, 생성 요청 상태에도 냉장고 ID를 결합하여 다른 냉장고 화면에 잘못된 상태가 표시되지 않게 처리했습니다.
