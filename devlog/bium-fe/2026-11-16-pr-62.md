## 변경 내용
- **재료 수정·삭제 409 충돌 처리**: `FridgePage.tsx`에서 버전 충돌(409) 시 냉장고 목록을 새로 불러오고 모달을 닫은 뒤 사용자 안내 메시지를 표시하도록 변경했습니다.
- **계정 전환 시 추천 목록 초기화**: `main.tsx`에서 `recipeStore`를 사전에 로드하여 토큰(계정)이 바뀔 때 이전 레시피 추천 목록(`bium-recipes`)이 초기화되도록 수정했습니다.
- **오래된 AI 추천 응답 무시**: 토큰 변경 시 요청 상태를 초기화하여 늦게 도착한 AI 레시피 추천 응답이 UI 상태에 반영되지 않도록 처리했습니다.
- **냉장고 재조회 시 추천 상태 유지**: `RecipePage.tsx`에서 냉장고 정보를 다시 불러오더라도 레시피 추천 진행 중 상태(버튼 잠금)가 해제되지 않게 수정했습니다.
- **활동 기록 갱신 순서 보장**: `SharePage.tsx`에서 활동 기록 요청을 `refreshActivities` 하나로 통합하고, 요청 시퀀스 번호를 통해 마지막 요청의 응답만 화면에 반영되도록 보장했습니다.
