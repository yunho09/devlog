## 요약
피드 상세 페이지에서 자신이 작성한 코멘트를 그 자리에서 바로 수정할 수 있는 인라인 수정 기능을 구현했습니다.
`PUT /api/feed/fridges/{fridgeId}/comments/{commentId}` API 통신 함수를 추가하고, `FeedComments` 컴포넌트에 수정 폼 전환, 입력값 검증, 반응형 레이아웃 및 포커스 복원 로직을 반영했습니다.
수정 실패 시 기존 데이터 복원 및 이미 삭제된 코멘트 예외 처리 등 안정적인 예외 대응 로직도 포함되었습니다.

## 변경 내용
- `src/api/feed.ts`: 피드 코멘트 수정 API 연동을 위한 `updateFeedComment` 함수 추가 (`PUT /api/feed/fridges/{fridgeId}/comments/{commentId}`).
- `FeedComments.tsx`:
  - 본인이 작성한 코멘트(`mine`)에 '고치기' 버튼 추가 및 클릭 시 인라인 수정 폼(내용/추천 음식 입력칸, 취소/저장 버튼, Esc 키 취소)으로 전환.
  - 작성 시와 동일한 길이 제한(내용 200자, 추천 음식 50자) 및 빈 내용 검증 적용. 추천 음식을 비우면 추천 없는 코멘트로 업데이트.
  - 저장 중 중복 요청 방지, 서버 응답 전 목록 미전환, 실패 시 원래 코멘트 유지 및 오류 안내. 이미 삭제된 코멘트(`FEED_COMMENT_NOT_FOUND`) 발생 시 목록에서 자동 제거.
  - 고치기·지우기 확인 상태에서는 다른 코멘트의 조작 버튼을 비활성화하고, 수정 폼이 닫힐 때 고치기 버튼으로 포커스 복원.
  - 760px 이하 해상도 대응을 위한 입력칸 세로 배치 반응형 스타일 적용.
- `feedFormat.ts`: `FEED_COMMENT_EDIT_FORBIDDEN` 오류 관련 안내 문구 추가.
