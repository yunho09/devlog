## 트러블 슈팅
- 화면에서 참조하는 냉장고와 헤더의 선택된 냉장고 정보 mismatch 문제 → 헤더와 동일하게 `getMyFridge()` 기준 냉장고 목록을 받아 사용하도록 수정 (`fa2354c`)
- 백엔드 400 에러 처리 및 입력 오류 문구가 명세와 불일치하던 문제 → 백엔드 에러 응답 구조(BAD_REQUEST, INVALID_INPUT)에 맞게 에러 문구 표시 로직 보완 (`411246d`)
- 냉장고에서 내보내졌을 때(FRIDGE_NOT_FOUND) 장보기 목록을 먼저 불러와 실패하는 문제 → 헤더의 냉장고 목록(`GET /api/fridges`)을 먼저 다시 수신한 뒤 장보기 목록을 불러오도록 처리 순서 변경 (`0d52525`)
- 항목 체크/삭제 시 다른 사용자에 의한 삭제(404)나 동시 변경(409) 시 오류 처리 문제 → 에러 수신 시 목록을 다시 불러오고, 불일치 상황에 맞는 사용자 안내 메시지 표시 (`8a5fd8d`)
- 빠른 재조회 요청 시 이전 응답이 늦게 도착하여 최신 상태를 덮어쓰는 경쟁 상태(Race Condition) 발생 → 가장 마지막에 요청한 응답의 결과만 UI 상태에 반영하도록 제어 (`4295c4c`)
