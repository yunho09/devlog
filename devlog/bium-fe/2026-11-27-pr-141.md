- `src/routes.tsx`에 `/join/:code` 추가 → `JoinInvitePage`
  - 코드를 `normalizeInviteCode`로 정리해 형식을 먼저 검사한다. 형식이 틀리면 참여 버튼 없이 안내만 보여 준다.
  - "참여하기"를 눌러야 기존 `joinFridge`로 참여한다. 요청 중에는 다시 보내지 않는다.
  - 결과 표시: 성공(‘냉장고 보러 가기’로 그 냉장고를 골라 `/fridge`로), 만료(`INVITE_EXPIRED`)·없는 코드·이미 멤버(`ALREADY_FRIDGE_MEMBER`, 헤더 목록 다시 받기)는 버튼을 '내 냉장고로 가기'로 바꾸고, 네트워크·서버 오류는 '다시 시도'를 보여 준다.
  - 헤더 모달과 같게, 기다리는 사이 계정이 바뀌면 참여한 냉장고를 목록에 넣지 않는다.
- 로그인 후 돌아오기
  - `RequireAuth`가 로그인 화면으로 보낼 때 열려던 주소를 `state.from`으로 넘긴다.
  - `LoginForm`은 로그인하면 `from`(이 앱 안 주소만, `//`로 시작하는 값은 무시)으로, 없으면 지금처럼 `/fridge`로 보낸다. 회원가입 뒤 로그인 폼으로 바뀌어도 같은 화면이라 그대로 유지된다.
- `InvitePanel`에 "링크 복사" 버튼 추가(`{origin}/join/{코드}`). 복사에 실패하면 링크를 직접 선택할 수 있게 보여 준다. 안내 문구에 링크로 참여하는 방법을 더했다.
