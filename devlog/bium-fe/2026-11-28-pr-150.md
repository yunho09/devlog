# 2026-11-28

## 요약
식재료 도감에서 사용자가 직접 추가한 재료 항목을 수정할 수 있는 기능을 추가했습니다. 기존 추가 모달(`IngredientAddModal`)을 수정 용도로 재사용할 수 있도록 확장하고, 수정 API 연동 및 서버 에러 반응 처리를 구현했습니다. 모바일 환경에서 카드의 버튼 줄이 넘치지 않도록 레이아웃도 함께 개선했습니다.

## 변경 내용
- **도감 수정 API 연동**: `PUT /api/ingredient-catalogs/{catalogId}` 요청을 처리하는 `updateCatalogIngredient` 함수 추가.
- **모달 컴포넌트 확장 (`IngredientAddModal`)**:
  - 추가 모달을 수정용으로 재사용할 수 있도록 props 및 내부 상태 로직 수정 (제목 "재료 수정", 버튼 "저장" 처리).
  - 수정 시 기존 재료 정보(이름, 아이콘, 카테고리, 기본 유통기한) 자동 바인딩.
  - 자기 자신의 이름은 중복 검사 대상에서 제외하는 로직 추가.
  - 요청 중 버튼 비활성화, 실패 시 서버 에러 코드(`DUPLICATE_CATALOG_NAME`, `INVALID_INPUT`, `CATALOG_NOT_FOUND` 등)에 따른 에러 메시지 노출.
- **카드 컴포넌트 개선 (`IngredientCard`)**:
  - 사용자가 추가한 재료 카드에 연필 형태의 수정 버튼(`aria-label` 포함) 추가.
  - 모바일 두 줄 카드에서 버튼 줄이 넘치지 않도록 상단 영역에 `flex-wrap` 적용.
- **페이지 상태 관리 (`LibraryPage`)**:
  - 재료 수정 모달 열기/닫기 및 수정 대상 데이터 전달 상태 관리.
  - API 응답 성공 후에만 UI 카드가 갱신되도록 처리.

## 의도
사용자가 식재료 도감에 직접 등록한 재료의 오탈자나 유통기한 등의 정보를 추후에 자유롭게 수정할 수 있도록 편의성을 제공하기 위함입니다.
