# 2026-11-28

## 요약
속한 냉장고가 없는 유저를 위한 새 냉장고 생성 기능과, 냉장고 소유자가 이름을 수정할 수 있는 기능을 추가하였습니다. 공통 모달인 `FridgeNameModal`을 새로 작성하여 이름 유효성 검사 및 서버 에러 안내 처리를 통합했습니다. 또한, 다중 기기 환경에서 발생할 수 있는 생성/수정 시 권한 오류나 중복 에러 등의 예외 처리를 반영했습니다.

## 변경 내용
- `FridgeNameModal` 컴포넌트 추가: 이름 유효성 검사(50자 제한, 빈 값 입력 제한) 및 서버 에러 메시지(INVALID_INPUT, FRIDGE_OWNER_ONLY 등) 모달 내부 노출 기능 구현
- `FridgePage` 개선: 연결된 냉장고가 없을 때 빈 상태 화면과 "새 냉장고 만들기" 버튼 추가, 생성 성공 시 `addFridge`·`selectFridge`를 통해 목록 동기화
- `SharePage` 개선: 냉장고 주인에게 이름 수정 버튼(`aria-label="냉장고 이름 바꾸기"`)을 노출하고, 수정 성공 시 헤더 및 화면 이름 업데이트
- `src/api/fridge.ts` API 추가: `createFridge` (`POST /api/fridges`), `renameFridge` (`PATCH /api/fridges/{fridgeId}/name`) API 정의

## 의도
냉장고에 속해있지 않은 신규 사용자의 이탈을 방지하고 서비스 진입 장벽을 낮추며, 냉장고 소유자 권한을 가진 사용자가 직접 이름을 변경하여 관리 편의성을 향상시키기 위함입니다.

## 트러블 슈팅
- 새 냉장고 생성 중 타 기기에서 이미 냉장고가 생성된 경우(`FRIDGE_ALREADY_EXISTS`) → 에러 발생 시 서버 목록을 재조회하여 최신 상태 동기화
- 이름 수정 요청 중 다른 기기에서 권한이 변동되거나 강퇴되어 실패하는 문제(403, 404 에러) → 실패 시 서버 냉장고 목록을 다시 불러와 현재 변경된 역할 상태를 화면에 반영
