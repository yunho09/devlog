# 2026-10-19

## 요약
공통 헤더(`AppHeader`)와 페이지 레이아웃(`AppLayout`)을 신규 구현하고, 경로(URL) 기반 라우팅 체계에 맞게 라우트를 재구성했습니다. 기존 상태 기반 화면 전환 방식을 라우팅 방식으로 전환하여 뒤로 가기와 새로고침이 가능하도록 개선했습니다. 미구현 라우트에는 `PreparingPage`를 임시 연결했으며, 중복 역할을 하던 `RecipeLayout`은 삭제했습니다.

## 변경 내용
- **공통 헤더 구현 (`AppHeader.tsx`)**: 브랜드 링크, 내 냉장고, 식재료 도감, AI 레시피 네비게이션 메뉴 및 `NavLink` 기반 활성 탭 표시, 키보드 포커스 테두리 제공.
- **공통 레이아웃 구현 (`AppLayout.tsx`)**: 헤더 하단 콘텐츠 영역의 폭과 여백을 통합 관리하는 레이아웃 추가.
- **준비 중 페이지 추가 (`PreparingPage.tsx`)**: 미구현 라우트(`/fridge`, `/library`)의 임시 안내 화면 추가.
- **기존 레이아웃 제거 (`RecipeLayout.tsx`)**: `AppLayout`으로 레이아웃 역할이 통합됨에 따라 파일 삭제.
- **라우트 구조 정리 (`routes.tsx`)**: 로그인 화면을 제외한 주요 경로를 `AppLayout` 하위로 그룹화하고 준비 중 화면 배치.

## 의도
Sprint 1 공통 헤더 작업의 일환으로, 기존 Bium-v1의 상태 기반 화면 전환 방식을 URL 라우팅 기반 구조로 개편하여 뒤로 가기 및 새로고침 동작을 지원하기 위함입니다. 화면별 `h1` 태그 중복을 피하기 위해 헤더 브랜드 로고는 `span` 태그로 작성했으며, 아직 화면이 개발되지 않은 냉장고 및 도감 페이지 담당자가 향후 라우트 경로만 쉽게 바꿀 수 있도록 공통 틀을 마련했습니다.
