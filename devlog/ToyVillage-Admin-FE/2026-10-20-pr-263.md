## 요약
API 승인 검증 방식을 기존 수동 `--by` 옵션 지정에서 `git config user.name` 기반 확인 방식으로 개선했습니다. 허가된 승인자 목록(`approvers.json`)을 검증하고, AI 세션(`CLAUDECODE`)에서의 자동 승인 명령 실행을 차단하도록 수정했습니다. 또한 승인 시점의 커밋 SHA를 기록하여 승인 이후의 변경 내역을 확인하고 diff 동의 후 재승인할 수 있는 절차를 추가했습니다.

## 변경 내용
- 승인자 지정 시 `--by` 옵션 대신 `git config user.name` 값을 읽어 `harness/api/approvers.json`에 정의된 사용자인지 확인하도록 변경
- `CLAUDECODE` 환경 변수가 존재하는 AI 세션 환경에서 승인 명령을 실행할 경우 승인 거부 처리
- 승인 기록에 승인 시점의 커밋 SHA를 저장하고, 승인 이후 변경 사항을 조회하는 `yarn harness:api:changes <feature>` 스크립트(`scripts/api-approval-changes.mjs`) 및 package.json 명령어 추가
- 재승인 시 승인 이후 변경된 diff를 먼저 출력하고 `y` 입력을 받아야 승인을 진행하도록 흐름 변경
- 재승인 시에도 기존 테스트 동결 해시를 유지하여 게이트 통과 우회 방지
- 실제 서버 비활성화 후 재승인할 때 실제 서버 동결 기록을 초기화하도록 수정
- 관련 하네스 유닛 테스트 추가 및 API 개발자 승인 절차 런북 문서 업데이트
