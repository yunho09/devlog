## 요약
업무지시 상세 페이지에서 업무보고 상세 페이지로 이동할 때 이전 경로 정보를 라우터 `state`로 전달하도록 개선했습니다. 이를 통해 업무보고 심사 완료 후 또는 뒤로가기 시 기존 업무지시 상세 페이지로 올바르게 복귀할 수 있게 되었습니다. 결과 토스트가 닫힐 때 상태를 비우는 로직과 함께 이를 검증하기 위한 E2E 테스트를 추가했습니다.

## 변경 내용
- **업무지시 상세 (`TaskDetailPage.tsx`)**: 업무보고 항목 클릭 시 이동 경로(`returnTo`)를 라우터 `state`에 실어 보내도록 변경하고, 승인/반려 결과 토스트를 표시 및 비활성화할 때 이동 state를 비우는 로직 추가.
- **업무보고 상세 (`TaskReportDetailPage.tsx`)**: 뒤로가기 및 심사 완료 시 `state.returnTo` 값이 존재하면 해당 경로로 이동하고, 존재하지 않으면 기본 업무보고 목록으로 이동하도록 대응.
- **E2E 테스트 (`task-report.spec.ts`)**: 업무보고 심사 완료 후 기존 업무지시 상세 화면으로 복귀하는 전체적인 비즈니스 흐름에 대한 E2E 테스트 케이스 작성.

## 의도
사용자가 업무지시 상세 화면에서 연결된 업무보고를 확인하고 심사할 때, 컨텍스트가 끊기지 않고 원래 보고 있던 업무지시 상세 화면으로 다시 원활하게 돌아갈 수 있도록 탐색(Navigation) 흐름을 매끄럽게 다듬기 위함입니다.

## 트러블 슈팅
- 문제 → 업무지시 상세 화면에서 특정 업무보고 상세 화면으로 진입한 뒤 심사를 완료하거나 뒤로가기를 누르면, 사용자가 이전에 보고 있던 맥락이 유실된 채 무조건 업무보고 목록 화면으로만 이동하는 사용성 불편이 있었습니다.
- 해결 → 라우터 이동 시 `returnTo`라는 임의의 상태(state)를 활용해 원래의 경로 정보를 넘겨주고, 업무보고 상세 페이지의 이탈 핸들러가 이 상태 값을 확인하여 이전 업무지시 화면으로 똑똑하게 복귀할 수 있도록 분기 처리를 구현했습니다.
