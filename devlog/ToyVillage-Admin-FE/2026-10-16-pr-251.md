## 요약
Sentry 클릭 기록(Breadcrumb) 및 세션 녹화 데이터에 직원 이름, 파일명 등 민감 정보가 포함되어 전송되던 문제를 해결했습니다. `aria-label`, `title`, `alt` 속성의 값을 마스킹하여 속성명만 남기도록 개선하고 세션 녹화 화면의 `alt` 텍스트도 가림 처리했습니다. 변경된 동작을 검증하기 위해 구분자가 포함된 라벨 케이스를 반영한 E2E 테스트를 작성했습니다.

## 변경 내용
- Sentry 클릭 이벤트 기록 시 요소 선택자에 포함되던 `aria-label`, `title`, `alt` 속성의 값을 제거하고 속성 이름만 남김 (`button[aria-label][title]` 형태)
- 세션 녹화(Session Replay) 내부 클릭 기록 및 녹화 화면상 `alt` 텍스트 가림 처리 적용
- Sentry 클릭 라벨 마스킹 동작 및 구분자가 포함된 라벨 처리를 검증하는 E2E 테스트 추가

## 의도
외부 에러 모니터링 서비스인 Sentry로 유저 행동 데이터가 수집될 때, 클릭된 요소의 접근성 속성(`aria-label`, `title`, `alt`)에 포함된 직원 이름 및 파일명 등의 개인정보/민감정보가 유출되는 것을 방지하기 위함입니다.
