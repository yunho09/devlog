- 직원 `role` 필드(`MIDDLE_ADMIN`, `EMPLOYEE`)를 기준으로 중간 관리자 목록과 지정 후보 분리
- 권한 부여(`MIDDLE_ADMIN`) 및 해제(`EMPLOYEE`) 처리 로직 작성

- 중간 관리자 지정 모달 UI를 라디오 버튼 기반 단일 선택으로 변경

- API 조회/지정/해제 실패 시 에러 문구 출력 및 모달/행 상태 유지 에러 핸들링 구현
