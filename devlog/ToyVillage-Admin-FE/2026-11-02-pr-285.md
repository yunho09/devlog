## 변경 내용
- **`GET /excel` API 연동**: 선택한 항목, 기간, 파일 형식을 쿼리로 요청하여 응답받은 바이너리 파일을 저장하는 기능 구현
- **파일명 생성 규칙 반영**: `{항목 이름 또는 통합}[_시작일_종료일].{xlsx|zip}` 포맷으로 파일명 자동 생성 (`exportFileName.ts`)
- **Figma 디자인 변경 반영**:
  - 내보내기 항목 10개 조정 (휴관일 관리 제거, 개체 및 먹이 항목 분리)
  - `ExportFormatField` 컴포넌트 추가를 통한 파일 형식 선택 기능 및 요약 카드 확장자 표시
- **예외 및 UI 처리**:
  - 성공("엑셀 파일을 내려받았습니다") 및 실패 토스트 메시지 노출
  - 413 에러 발생 시 서버 메시지(최대 건수/총용량 초과) 표시
  - 엑셀 다운로드 요청의 axios `timeout`을 5분으로 확장 (공통 10초)
- **공용 컴포넌트 확장**: `Toast` 컴포넌트에 선택적 `fitContent` prop 추가
- **테스트 및 명세**: E2E 테스트 작성 및 harness API 계약/명세 문서 추가
