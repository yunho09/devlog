## 트러블 슈팅
- **먹이 급여 상세 로딩 시 레이아웃 이탈 현상** → 상세 데이터 조회 완료 전 스켈레톤 처리 단계에서도 실제 카드와 이력 표 레이아웃을 미리 그리도록 구조를 맞춰 레이아웃이 튀지 않게 수정 (`b0fbd8d`).
- **E2E 테스트 애니메이션 및 대기 시간 불일치로 인한 실패** → 공지 생성 모달 크기 비교를 애니메이션이 완료된 후에 수행하도록 수정하고, 업무일지 재조회 e2e 테스트는 요청 완료까지 명시적으로 대기하도록 수정 (`e650a7f`, `6fb1638`).
- **Swagger 비교 CI의 캐시 및 조회 타임아웃** → Swagger 비교 CI 실행 시 패키지 매니저 자동 캐시를 해제하고 타임아웃 발생 시 사유 미확인 차이 메시지가 명확히 표시되도록 정비 (`13fb0cd`, `84833ac`).
- **라우트 코드 스플리팅 후 주소 전환 지연 문제** → 화면 지연 로딩 로직을 개선하고, 로딩 공백기 동안 보일 로그인 스켈레톤 컴포넌트를 추가하여 주소 전환 지연 현상 해결 (`1078290`, `3b5a62b`).
- **Sentry 모니터링 시 민감 버튼 라벨 수집 문제** → 클릭 이벤트를 기록할 때 라벨 값을 제거하고 요소 정보 기반으로 로그를 다시 생성하여 개인정보 노출 방지 (`9c325a9`, `ba75515`).
