# 2026-09-17

## 요약
어드민 페이지의 사이드바 로그아웃 버튼에 실제 로그아웃 API(`POST /app/auth/logout`)를 연동했습니다. API 연동 과정에서 명세 문서와 테스트 시나리오를 정의하고, 기존 로그아웃 로직을 `useLogout` 커스텀 훅으로 리팩토링했습니다. 또한, 기능 검증을 위한 E2E 테스트를 새롭게 추가했습니다.

## 변경 내용
- **API 연동**: `POST /app/auth/logout` 호출을 위한 API 함수 및 타입을 `src/entities/auth` 내에 정의했습니다.
- **사이드바 리팩토링**: 기존 `logout.ts` 모델 파일을 제거하고, API 연동 로직을 내포하는 `useLogout.ts` 커스텀 훅을 새로 도입하여 `Sidebar.tsx` 컴포넌트에 적용했습니다.
- **API 명세 및 승인 문서 추가**: `harness/api` 경로 하위에 로그아웃 API에 대한 계약(Contract), 승인 문서, 구현 계획서, 테스트 시나리오 마크다운 파일 등을 추가했습니다.
- **E2E 테스트 코드 작성**: 로그아웃 API의 정상 동작 여부를 확인하기 위해 `tests/e2e/api/app-auth-logout.spec.ts` 파일을 작성했습니다.

## 의도
사용자가 어드민 페이지에서 안전하게 로그아웃할 수 있도록 서버 세션 및 토큰을 만료시키는 API를 연동하고자 했습니다. 또한 API 계약 문서를 함께 관리하고 E2E 테스트를 추가함으로써 기능의 변경에 안정적으로 대응할 수 있도록 설계했습니다.
