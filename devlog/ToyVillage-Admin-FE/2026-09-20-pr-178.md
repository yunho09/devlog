# 2026-09-20

## 요약
로딩 스켈레톤에 1.4초 주기 주기로 반복되는 쉬머(Shimmer) 애니메이션을 추가하고, 미디어 쿼리를 통해 동작 감소 설정을 지원하도록 개선했습니다. 기존의 페이지 단위 스켈레톤 컴포넌트를 대거 제거하는 대신, 로딩 중에도 헤더, 뒤로가기, 탭, 라벨 등의 정적 UI 레이아웃을 그대로 유지하고 데이터 영역만 스켈레톤으로 채워지도록 대대적인 구조 개편을 수행했습니다. 이와 더불어 지연 조회 시 정적 UI가 올바르게 유지되는지 검증하는 E2E 테스트와 피그마 기준의 명세를 최신화했습니다.

## 변경 내용
- **쉬머 애니메이션 도입**: `Skeleton.tsx`에 1.4초 주기의 linear 무한 반복 쉬머 애니메이션을 적용하고, `prefers-reduced-motion` 환경에서는 움직임이 멈추도록 예외 처리를 반영했습니다.
- **정적 UI 복원 및 스켈레톤 리팩터링**: 
  - `DashboardSkeleton`, `NoticeListSkeleton`, `TaskListSkeleton` 등 약 10개 이상의 대형 페이지 단위 스켈레톤 컴포넌트들을 삭제했습니다.
  - 목록, 상세, 수정, 대시보드 화면 전반에서 뒤로가기 버튼, 제목, 필드 라벨, 탭, 검색/필터 컨트롤 등 고정 UI는 로딩 중에도 원본 그대로 유지되며, 실제 데이터 영역만 스켈레톤으로 표시되도록 변경했습니다.
- **E2E 테스트 및 문서 보강**: 지연된 조회 과정 중 정적 UI와 스켈레톤이 깨지지 않고 유지되는지 검증하는 E2E 테스트를 추가 및 수정하였고, 피그마 기준의 스켈레톤 시나리오 명세 문서를 업데이트했습니다.

## 의도
사용자가 로딩 중에도 현재 진입한 페이지의 맥락(헤더, 필터, 탭 레이아웃 등)을 잃지 않고 인지할 수 있도록 돕기 위함입니다. 화면 전체가 텅 비거나 깜빡이는 현상을 방지해 시각적 안정성을 높이고, 실제 데이터가 표시될 구역에만 부드러운 쉬머 애니메이션 효과를 주어 앱의 실시간 반응 체감을 개선하고자 했습니다.
