# 2026-09-17

## 요약
개체 상세 페이지 내 '먹이 급여 기록 확인하기' 버튼을 최신 급여 기록 상세 페이지로 라우팅하는 기능을 추가했습니다. 버튼 클릭 시 해당 개체의 급여 이력을 조회하며, 데이터가 없거나 조회에 실패하는 예외 케이스 발생 시 페이지를 이동하는 대신 토스트 에러 메시지를 표시하도록 처리했습니다. 이와 관련된 E2E 테스트 코드 작성과 승인 명세서 업데이트를 함께 진행했습니다.

## 변경 내용
- **개체 상세 라우팅 구현**: `IndividualDetailPage.tsx`에서 개체 상세 내 급여 기록 확인하기 버튼을 클릭했을 때 최신 급여 이력 상세 페이지로 이동하도록 로직을 추가했습니다.
- **예외 처리 및 토스트 안내**: 급여 기록이 존재하지 않거나 API 조회에 실패하는 경우, 화면을 이동하지 않고 에러 토스트를 띄우도록 제어했습니다 (`usePageToast.ts` 활용).
- **API 및 쿼리 설정 보완**: 급여 기록 조회와 관련된 API 함수 및 리액트 쿼리 키 구조를 수정하고 내보냈습니다 (`feedApi.ts`, `queryKeys.ts`).
- **E2E 테스트 추가**: 이동 성공 케이스 외에도 급여 기록 부재, API 오류 상황에 대한 토스트 노출을 검증하는 E2E 테스트를 `individual-detail.spec.ts`에 추가했습니다.
- **명세 및 승인 문서 갱신**: 시나리오 초안 및 테스트 명세 변경 사항을 승인 파일(`individual-detail.approved.json` 등)에 반영했습니다.

## 의도
개체를 관리하는 사용자가 상세 화면에서 즉각적으로 최신 급여 상태를 파악할 수 있도록 진입 경로를 단축하기 위함입니다. 또한, 급여 기록 데이터가 존재하지 않거나 네트워크 오류가 발생하는 불안정한 환경에서도 사용자에게 빈 화면이나 에러 페이지를 보여주는 대신, 토스트 메시지로 상황을 명확하게 인지시켜 UX를 향상하고자 했습니다.
