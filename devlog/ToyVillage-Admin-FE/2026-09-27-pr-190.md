# 2026-09-27

## 요약
자료실 상세 및 관찰 상세 페이지의 첨부파일 영역에 이미지 미리보기 기능을 연결하였습니다. 이제 첨부파일명을 클릭하면 미리보기 대화상자가 나타나며, 다운로드 아이콘을 누를 때만 파일이 즉시 다운로드되도록 동작을 분리했습니다. 이와 더불어 변경된 인터랙션에 맞춰 E2E 테스트를 보강하고 관찰 상세 페이지의 키보드 포커스 순서 오류를 수정하였습니다.

## 변경 내용
- **첨부파일 미리보기 연동**: `ResourceViewPage`(자료실 상세) 및 `ObservationDetailPage`(관찰 상세)의 첨부파일 칩 컴포넌트에 미리보기 기능을 연결했습니다.
- **인터랙션 다변화**: 파일명을 클릭하면 미리보기 팝업이 뜨고, 다운로드 아이콘을 클릭할 때만 실제 파일 다운로드가 동작하도록 변경했습니다.
- **E2E 및 승인(Approval) 테스트 반영**: 새로 추가된 이미지 미리보기 시나리오를 검증하기 위해 테스트 명세(`specs/attachment-preview.spec.md`)를 보강하고 관련 E2E 테스트 코드와 승인 스냅샷 데이터를 갱신했습니다.
- **키보드 접근성 수정**: 관찰 상세 화면 내에서 키보드 탭 키로 이동 시의 포커스 순서가 올바르게 작동하도록 e2e 테스트 스펙과 코드를 조정했습니다.

## 의도
사용자가 자료실이나 관찰 내역을 조회할 때, 매번 첨부파일을 로컬 컴퓨터에 다운로드하지 않고도 화면상에서 이미지 내용을 쉽고 빠르게 확인하도록 유도하여 사용성을 개선하고자 했습니다. 또한 단순 뷰어 기능과 실제 다운로드 기능을 명확히 구분하여 불필요한 네트워크 리소스 낭비를 방지하고자 한 것으로 보입니다.

## 트러블 슈팅
- **관찰 상세 화면의 키보드 접근성 순서 불일치 → e2e 초점 순서 수정 후 스냅샷 재동결**:
  - 관찰 상세 화면의 구현 혹은 마크업 구조 상에서 키보드 탭 키를 누를 때 포커스가 가야 하는 논리적인 흐름과 실제 e2e 테스트에서 기재한 초점 순서가 맞지 않는 문제가 있었습니다.
  - 이를 해결하기 위해 관찰 상세 e2e 명세에서 올바른 초점 이동 순서를 정의하여 코드를 반영한 후, 다시 해당 테스트 결과(freeze)를 갱신하여 해결했습니다 (`5842e31`).
