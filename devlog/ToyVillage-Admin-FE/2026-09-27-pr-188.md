# 2026-09-27

## 요약
이번 PR은 공지사항, 업무 및 업무보고 상세 화면에서 첨부파일(이미지 및 PDF)을 로컬에 다운로드하지 않고 웹상에서 바로 확인할 수 있는 미리보기 모달 기능을 구현했습니다. 이미지 파일은 비율을 유지하여 표시하고, PDF 파일은 페이지별 이동 기능을 지원하며, 그 외의 형식은 클릭 시 즉시 다운로드되도록 처리했습니다. 비동기 작업 중단 처리, 반응형 높이 제한, 웹 접근성을 위한 라이브 영역 추가 등 뷰어의 완성도를 높이는 예외 처리를 함께 반영했습니다.

## 변경 내용
- 공지사항 및 업무보고 상세 화면에서 첨부 파일명을 클릭하면 나타나는 미리보기 모달 컴포넌트(`AttachmentPreviewDialog`)를 추가했습니다.
- 미리보기 지원 형식(JPG, JPEG, PNG, GIF, WEBP, PDF)을 식별하여, 이미지 형식은 비율을 유지하며 렌더링하고 PDF는 `‹ 1 / N ›` 페이지 이동 내비게이션을 통해 조회하는 기능을 구현했습니다.
- 이미지와 PDF가 아닌 기타 포맷의 파일은 클릭 시 기존처럼 즉시 다운로드되도록 구현했습니다.
- 미리보기 모달은 닫기 버튼, Escape 키 입력, 혹은 배경 영역 클릭 시 닫히도록 구성했으며, 닫힌 후에는 이전 포커스 위치로 복귀하도록 구현했습니다.
- PDF 렌더링 처리를 위해 `pdfjs-dist` 라이브러리 의존성을 새로 추가했습니다.

## 의도
사용자가 첨부된 이미지나 문서를 확인할 때 매번 로컬 디바이스에 파일을 내려받아야 하는 번거로움을 줄이고, 브라우저 내부에서 신속하게 내용을 확인할 수 있게 함으로써 관리자 페이지의 전반적인 업무 효율성과 사용성을 높이고자 했습니다.

## 트러블 슈팅
- **미리보기 로딩 중 모달을 빠르게 닫았을 때 비동기 리소스가 낭비되는 문제** → 모달이 해제되면 대기 중이던 파일 네트워크 요청과 PDF 해석(Parsing) 처리를 즉시 중단(Abort)하도록 예외 처리를 반영했습니다. (`dfa773c`)
- **스크린 리더 사용자가 로딩 및 오류 메시지의 갱신을 인지하지 못하는 문제** → 모달 로딩 문구와 로드 실패 문구 엘리먼트에 ARIA 라이브 영역(Live Region) 속성을 부여해 웹 접근성을 개선했습니다. (`28b779a`)
- **PDF 파일 해석 중 오류 발생 시 화면 처리가 누락되는 문제** → 렌더링에 실패하더라도 모달이 빈 화면으로 멈추지 않고, 뷰어 내에 로드 실패 상태를 명시적으로 나타내도록 오류 처리를 강화했습니다. (`0220318`)
- **세로 해상도가 낮은 디바이스에서 모달 창이 화면을 벗어나는 문제** → 반응형 대응을 위해 최대 높이 제한 속성을 설정하고 내부 스크롤을 활성화하여 모달 크기가 화면을 넘지 않도록 스타일을 최적화했습니다. (`9e48475`)
