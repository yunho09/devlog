# 2026-09-17

## 요약
로그인 실패 시 사용자에게 시각적 피드백 없이 비밀번호 필드만 비워지던 문제를 해결하기 위해 Figma 디자인 명세를 바탕으로 오류 안내 기능을 구현했습니다. 자격증명 불일치(401) 에러가 발생하면 비밀번호 입력란 하단에 경고 문구를 표시하고, 그 외의 에러(5xx, 네트워크, 응답 형식 오류 등)가 발생하면 토스트 알림을 띄우도록 이원화했습니다. 또한, 해당 로그인 실패 시나리오가 올바르게 작동하는지 검증하기 위해 명세서 업데이트 및 E2E 테스트를 추가했습니다.

## 변경 내용
- **로그인 실패 피드백 구현**:
  - **401 Unauthorized (자격증명 오류)**: 비밀번호 입력 필드 하단에 "아이디 또는 비밀번호를 확인해주세요" 안내 문구 노출.
  - **기타 오류 (5xx, 네트워크 등)**: "로그인에 실패했습니다" 토스트 메시지 노출.
- **문서 및 명세 업데이트**: 로그인 실패 상태와 시나리오를 정의하는 명세 문서 및 Figma 연동 파일 업데이트.
- **E2E 테스트 추가**: 로그인 실패 케이스별 피드백이 정상적으로 렌더링되고 작동하는지 검증하는 E2E 테스트 코드 작성.

## 의도
로그인에 실패했을 때 아무런 안내 없이 입력 필드만 초기화되면 사용자는 로그인 프로세스가 정상적으로 동작했는지, 어떤 이유로 실패했는지 인지하기 어렵습니다. 따라서 에러의 원인(인증 정보 오류 vs 시스템/네트워크 오류)을 명확히 구분하여 Figma 명세에 맞는 직관적인 피드백을 제공함으로써 사용자 경험(UX)을 개선하고자 했습니다.
