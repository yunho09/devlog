사이드바 하단에 로그아웃 기능을 퍼블리싱하고, 세션 삭제 및 로그인 페이지 리다이렉션 동작을 구현했습니다. 로그아웃 후 뒤로 가기 방지 및 미인증 사용자 접근 제한 등 세부 보안 동작을 적용했습니다. 이와 함께 로그아웃 시나리오 정의 및 E2E 테스트 코드를 추가하여 안정성을 검증했습니다.

## 변경 내용
- **로그아웃 버튼 UI 추가**: 사이드바 하단 영역에 로그아웃 버튼(`SidebarLogoutButton.tsx`) 및 구분선, SVG 아이콘을 추가했습니다.
- **레이아웃 대응**: 화면 높이가 낮은 뷰포트에서도 로그아웃 버튼을 정상적으로 확인하고 사용할 수 있도록 CSS를 조절했습니다.
- **인증 및 세션 처리**: 로그아웃 시 세션 정보를 삭제하고 로그인 화면으로 강제 이동하며, 뒤로 가기로 이전 화면에 접근할 수 없도록 이력을 제어합니다.
- **명세 및 E2E 테스트 추가**: 로그아웃 행동 명세(`logout.spec.md`) 및 시나리오를 정의하고, 기능이 정상적으로 동작하는지 검증하기 위한 Playwright 기반의 E2E 테스트 코드(`tests/e2e/logout.spec.ts`)를 작성했습니다.

사용자가 안전하게 세션을 종료할 수 있도록 명확한 UI 인터페이스를 제공하기 위함입니다. 또한, 로그아웃 처리 후 브라우저 뒤로 가기를 통해 이전 인증 영역에 다시 접근할 수 없도록 동작을 제어하여 관리자 시스템의 보안성을 강화하고자 했습니다.
