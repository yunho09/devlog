- **명세 및 E2E 테스트 업데이트**: 직접 추가한 법정지정분류가 서버 공용 목록에 공유된다는 기획 사양을 정정하고, 이에 맞춰 하네스 API 승인 파일, 시나리오 명세 및 E2E 테스트 코드를 대폭 보강했습니다.
