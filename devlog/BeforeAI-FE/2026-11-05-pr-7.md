## 트러블 슈팅
- 위험도를 `FORBIDDEN`으로 바꾸거나 상태를 `RUNNING`으로 변경 시 서명 없이 실행되던 문제 → 검증 완료된 작업을 세션에 고정하고 실행 완료 후 세션을 종료하도록 로직을 수정하여 상태 변조 우회 차단
- 금지 규칙에 걸린 문서 롤백 시 승인 대기에 멈췄다가 새로고침하면 서명 없이 롤백되던 문제 → `422 FORBIDDEN_TASK` 에러 코드를 반환하도록 수정하여 차단
- 본인 승인 시 검토하지 않은 내용에 자동 서명되던 문제 → 사용자 검토 및 확인 절차를 거쳐서만 본인 서명이 첨부되도록 보강
