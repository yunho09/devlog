## 요약
승인 상세 및 요청 상세 화면에 결재 문서 미리보기와 PDF 내려받기 기능을 추가했습니다.
아코디언 형태의 미리보기 섹션을 펼칠 때만 PDF를 비동기로 요청하며, 판(버전)이 여러 개인 경우 이전 판 선택 조회 및 최신 승인 완료 판만 다운로드할 수 있도록 처리했습니다.
또한 웹쉘 검증 실패, 무결성 검증 실패, 잘못된 PDF 헤더 응답에 대한 보안 예외 처리를 추가하고 시연용 목(Mock) API를 함께 구현했습니다.

## 변경 내용
- **결재 문서 미리보기 및 PDF 내려받기 기능 구현**: 승인 및 요청 상세 화면에 펼침/접기 가능한 결재 문서 섹션 추가.
- **다중 판(버전) 관리**: 2개 이상의 판이 존재하는 경우 이전 판 선택 기능 제공 (이전 판은 보기 전용, 최신 승인 완료 건만 다운로드 허용).
- **보안 검증 로직 강화**:
  - 무결성 확인 실패 시 문서 미표시 및 승인 버튼 잠금.
  - 웹쉘 검증 실패 요청은 서버 응답 상태가 `APPROVED`여도 내려받기 차단 및 경고 표시.
  - `%PDF-` 헤더가 없는 응답은 표시 및 저장 차단.
- **오프라인 시연용 목(Mock) API 추가**: 서버 없이도 미리보기, 도장 표시, 판 전환 등을 시연할 수 있는 라우트 및 이미지 PDF 생성 로직 작성.

## 의도
사용자가 결재 관련 상세 화면에서 최종 승인 문서나 과거 판의 이력을 직접 확인하고 보관할 수 있도록 하기 위함입니다.
동시에 결재 프로세스 중 발생할 수 있는 문서 변조, 무결성 훼손, 유효하지 않은 파일 다운로드 등의 보안 위협을 프론트엔드 차원에서 차단하고자 했습니다.
