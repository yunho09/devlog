- **실시간 연결:** SSE 재접속(`Last-Event-ID`), 끊긴 연결 감지, 로그 이어 받기
- **명세 대조:** 페이지 전체 읽기, 명세에 없는 필드가 빠져도 거짓 "통과"나 화면 오류가 없게 처리
- **실제 서버 빌드:** 시연 계정, 시연 문구, 목 코드 제거
- **개발 설정:** `VITE_API_PROXY_TARGET` 프록시, `.env.example`, README 안내
