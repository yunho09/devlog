# 2026-11-05

## 요약
AI가 생성한 듯한 과도한 디자인 장식을 제거하고 GitHub Actions 및 Linear 스타일의 정돈된 업무 도구 UI로 개선한 PR입니다. 화면 흐름과 기존 기능은 유지하면서 디자인 토큰, 상태 표시 방식(이모지 및 알약 형태 제거), 트리 뷰 및 로그인 UI를 다듬었습니다. 작업 과정에서 발생한 트리 배너 문구 겹침 문제와 개발 도구 위치 수정 커밋도 함께 반영되었습니다.

## 변경 내용
- **디자인 토큰 개편**: 흰색 배경, 밝은 사이드바, 1px 테두리, 단일 파란색 강조색, 모달류 제외 그림자 제거 등을 적용했습니다.
- **상태 표시 및 식별자 단순화**: 🟢🟠🔴 이모지와 색상 알약 형태를 제거하고 작은 기호와 색상 텍스트 조합으로 다듬었습니다.
- **레이아웃 구조 정돈**: 카드를 단순 열거하던 방식에서 단일 상자 내부의 행(Row) 구조로 변경하고 제목 주변의 아이콘 장식을 없앴습니다.
- **트리 컴포넌트 개선**: 점 격자, 빗금, 색 띠를 제거하고 흰 상자 및 좌측 상태 선 기반 UI로 정돈했습니다.
- **로그인 화면 비주얼 수정**: 어두운 패널의 비주얼을 결재 문서 및 도장 모션 애니메이션으로 교체했습니다.
- **버그 수정**: 트리 컴포넌트와 겹치는 배너 문구 레이아웃을 정리하고 로그인 화면 내 개발 도구 위치를 수정했습니다.

## 의도
지나치게 과도하거나 산만한 UI 요소(AI 생성물 특유의 장식적인 스타일)를 배제하고, 일관되고 깔끔한 업무용 도구 감성을 제공하여 사용자 경험과 제품 신뢰도를 높이기 위함입니다.
