## 요약
약품 스캔 버튼을 클릭했을 때 사진 촬영과 라이브러리 선택 옵션을 제공하는 바텀 시트(Bottom Sheet) 기능을 구현했습니다. 기존 수동 입력 영역 바로 위에 버튼을 유지하면서, 클릭 시 두 가지 소스를 선택할 수 있는 직관적인 흐름을 설계했습니다. 후면 카메라 촬영 및 기존 멀티 사진 입력과의 연동을 완료하고 백드롭, 취소 버튼, ESC 키를 통한 닫기 기능을 추가했습니다.

## 변경 내용
- 수동 입력 바로 위에 있는 스캔 버튼이 '사진 촬영(Take a photo)' 및 '사진 라이브러리에서 선택(Choose from photo library)' 액션을 포함한 바텀 시트를 열도록 변경했습니다.
- 카메라 캡처 기능을 후면 카메라(rear-facing camera) 사용으로 연결했습니다.
- 라이브러리 선택 기능을 기존의 멀티 사진 입력(multi-photo input) 인터페이스와 연동했습니다.
- 바텀 시트의 백드롭 영역, 취소 버튼 및 ESC 키(Escape)를 통한 시트 닫기 기능을 구현했습니다.

## 의도
사용자가 단일 스캔 버튼을 통해 사진 촬영과 기존 앨범 업로드라는 두 가지 이미지 입력 방식을 직관적이고 편리하게 선택할 수 있도록 사용자 경험(UX)을 개선하기 위함입니다.
