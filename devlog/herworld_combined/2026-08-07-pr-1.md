## 요약
약 사진 등록 시 카메라 촬영과 사진 보관함 선택을 명시적으로 구분할 수 있는 하단 소스 선택기(Source Picker)를 추가했습니다. 일부 모바일 브라우저에서 단일 파일 입력 태그 사용 시 카메라가 호출되지 않고 사진 라이브러리만 열리던 문제를 해결했습니다. 카메라는 후면 카메라 조작을 요청하며, 라이브러리 선택은 최대 4장의 제한 내에서 다중 업로드를 지원합니다.

## 변경 내용
- **약 사진 소스 선택기 추가**: 화면 하단에서 카메라 촬영 또는 사진 라이브러리를 선택할 수 있는 UI 구현
- **카메라 촬영 기능 구현**: 후면 카메라를 명시적으로 요청하도록 처리
- **사진 라이브러리 연동**: 최대 4장 제한 범위를 유지하며 다중 사진 등록 지원
- **사용자 경험 개선**: 백드롭 영역 클릭, 취소 버튼 누르기, 또는 Escape 키 입력을 통한 선택기 닫기 기능 지원
- **스타일 정의**: 소스 선택기 디자인 및 레이아웃을 위한 전용 CSS 스타일 정의

## 의도
이전 방식인 단일 파일 입력(`input` 태그)은 소스 선택 권한을 브라우저에 위임하여, 일부 모바일 기기 및 브라우저 환경에서 사진 보관함만 열리고 카메라 촬영을 선택할 수 없는 문제가 있었습니다. 웹 환경에서 모바일 기기의 카메라와 라이브러리 접근을 명시적으로 제어하여 일관된 사용자 경험을 제공하고자 이번 변경을 진행했습니다.
