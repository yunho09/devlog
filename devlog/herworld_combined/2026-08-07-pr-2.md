## 요약
약물 스캔 화면에서 카메라와 갤러리를 선택하는 기존 바텀 시트(Bottom Sheet)를 제거하고 UI 레이아웃을 개편했습니다. 수동 입력 버튼 바로 위에 직관적인 전용 카메라 버튼을 배치하고, 기존 대형 카드는 갤러리 불러오기 기능으로 유지했습니다. 이를 통해 사용자가 불필요한 단계를 거치지 않고 원하는 동작을 즉시 수행할 수 있도록 개선했습니다.

## 변경 내용
- 카메라/갤러리 선택용 바텀 시트 제거
- 기존 대형 사진 카드를 사진 라이브러리(갤러리) 불러오기 전용 액션으로 유지
- 수동 입력(`Enter without a photo`) 바로 위에 노출되는 `Camera` 버튼 신설
- 후면 카메라 캡처 입력과 멀티 사진 라이브러리 입력을 독립된 상태로 분리 유지
- 바텀 시트 제거에 따른 불필요한 스타일 코드 및 컴포넌트 로직 정리
