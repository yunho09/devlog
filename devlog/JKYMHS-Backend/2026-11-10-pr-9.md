# 2026-11-10

## 요약
이메일 회원가입 및 비밀번호 재설정을 위한 인증 코드 발송·검증 API를 추가했습니다. Redis와 Lua 스크립트를 활용해 동시성 문제, 60초 재전송 제한, 오입력 5회 제한, IP별 요청 제한을 원자적으로 처리했습니다. 메일 발송에는 `spring-boot-starter-mail`과 Mailpit을 도입하였으며 타이밍 공격 방지 등 보안 처리를 함께 적용했습니다.

## 변경 내용
- 이메일 인증 코드 발송(`POST /api/auth/email/send`) 및 검증(`POST /api/auth/email/verify`) API 추가
- DTO compact constructor를 통한 이메일 정규화(`trim().toLowerCase()`) 및 `SecureRandom` 6자리 숫자 코드 생성
- Redis 기반 인증 데이터 저장 (`auth:code:{purpose}:{email}`, TTL 5분, Lua 스크립트로 HSET + PEXPIRE 원자적 실행)
- IP 기반 요청 제한(1분 5회) 및 60초 재전송 쿨다운 제한 처리
- 검증 시 오입력 5회 제한(Lua 스크립트로 키 확인 및 `HINCRBY` 원자 처리) 및 `MessageDigest.isEqual`을 이용한 타이밍 공격 방지
- 코드 검증 성공 시 10분 유효 기간의 `verificationToken` 발급 (`auth:verified:{purpose}:{email}`)
- `RESET_PASSWORD` 요청 시 미가입 이메일도 동일하게 처리해 가입 여부 노출 방지
- `spring-boot-starter-mail` 동기 메일 발송 및 로컬 테스트용 Mailpit 서비스 구성 (`compose.yaml`)
- 동시 검증 시 토큰 발급 미작동 문제 해결 커밋 반영

## 의도
이메일 인증 로직에서 발생할 수 있는 동시성 이슈(시도 횟수 제한 우회, 중복 토큰 발급 등) 및 응답을 통한 계정 존재 여부 탐지 등 보안 취약점을 차단하기 위해 작성되었습니다. 메일 서버 장애나 네트워크 지연 시 DB 커넥션 점유 및 무한 대기를 방지하도록 타임아웃과 원자적 Redis 조작을 적용했습니다.
