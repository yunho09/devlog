## 요약
모집의뢰서 신청(지원하기) 페이지를 새롭게 퍼블리싱하고 연동 작업을 완료했습니다. 학생이 채용 상세 정보를 기반으로 포트폴리오, 자기소개서, 링크 등을 입력해 지원할 수 있는 화면과 라우터를 추가했습니다. 또한 잘못된 채용 정보로 접근할 경우 예외 처리를 통해 목록 페이지로 리다이렉트하는 흐름을 구현했습니다.

## 변경 내용
- **지원하기 페이지 신설**: `recruitment-apply` 폴더 하위에 지원 페이지 구현. 회사 정보 확인 및 자기소개서, 포트폴리오, 첨부파일, 관련 링크를 입력하는 폼 UI 배치.
- **라우터 등록 및 Loader 처리**: `router.tsx`에 지원하기 경로를 추가하고, `loader.ts`를 통해 유효하지 않은 채용 정보로 접근 시 채용 목록으로 강제 이동되도록 제어.
- **환경 설정 무시**: `.gitignore` 파일에 로컬 개발 상태 관련 파일(`.omc`)을 무시하도록 설정 추가.
- **코드 포맷팅 및 린트 정리**: Prettier 포맷팅 수정 및 디자인 시스템의 일부 타입, 회원가입 훅(`useSignUp`) 관련 코드 마이너 정리.

## 의도
학생 사용자가 특정 기업의 채용 공고를 확인한 후, 필요한 제출 자료(자기소개서, 포트폴리오, 웹 링크 등)를 누락 없이 손쉽게 입력하고 지원을 완료할 수 있도록 사용자 경험을 개선하기 위함입니다. 또한 잘못된 파라미터나 만료된 채용 정보 페이지로 잘못 진입했을 때 발생할 수 있는 에러 상황을 라우터 수준에서 방어하고자 했습니다.
