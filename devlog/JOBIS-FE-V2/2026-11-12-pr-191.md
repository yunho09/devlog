## 주요 변경 사항
- (AD) 협약 토스트
  - `PATCH /companies/mou`는 선택한 기업마다 협약 여부를 뒤집습니다(BE `Company.convertToMou`).
  - 요청 전 선택한 기업들의 `convention`으로 문구를 고릅니다.
    - 모두 협약 → "협약이 해제되었습니다."
    - 섞여 있음 → "협약 여부가 변경되었습니다."
    - 모두 미협약 → "협약이 등록되었습니다."
  - 실패 문구는 "협약 변경에 실패했습니다."
- (AD) 지원서 첨부 표시
  - `url.split("-")`의 마지막 조각을 쓰던 표시를 바꿨습니다.
    - 링크: 프로토콜을 뺀 주소
    - 파일: `getUploadedFileName`(업로드 uuid 접두사 제거). 전에는 `-`가 들어간 파일명도 잘렸습니다.
  - 긴 이름은 200px에서 말줄임, 마우스를 올리면 전체 이름 표시(`title`)
  - 펼친 첨부 목록에서는 말줄임 없이 줄바꿈으로 전체 이름 표시 (키보드·터치 사용자용)
  - 첨부 칸을 키보드로도 열 수 있게 `role="button"`, `tabIndex`, `aria-expanded`, Enter/Space 처리
  - 다운로드 경로는 `toFileUrl` 사용
