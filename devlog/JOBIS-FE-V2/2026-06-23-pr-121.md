# 2026-06-23

## 요약
학생들이 면접 후기를 편리하게 작성할 수 있도록 돕는 연결 페이지(`/connect-review`)와 홈 화면 내 작성 유도 배너를 새롭게 구현하였습니다. 이를 위해 면접 내역을 조회하는 API를 패키지에 신설하였으며, UI 요구사항에 맞추어 공용 버튼 컴포넌트의 옵션을 확장하였습니다.

## 변경 내용
- **면접 후기 연결 페이지 구현**: `/connect-review` 경로로 접근 가능한 신규 페이지 및 데이터 로더를 추가하고 라우팅을 등록했습니다.
- **홈 화면 면접 배너 추가**: 면접 이력이 존재할 때 사용자에게 알리는 메인 배너를 홈 화면에 연동하였으며, 회사명을 동적으로 표시하고 0건일 때의 예외 처리와 매직 넘버 제거 작업을 진행했습니다.
- **인터뷰 API 정의**: 면접 본 내역을 조회하기 위해 `packages/api` 내에 `interviews` 관련 API 함수, 쿼리 키, 타입을 신설했습니다.
- **공용 버튼 컴포넌트 확장**: `Button` 컴포넌트에 패딩 옵션 및 hover 효과 커스터마이징을 위한 속성을 추가했습니다.

## 의도
학생 사용자가 면접 일정을 마친 후, 서비스에 진입했을 때 자연스럽게 면접 후기를 작성하도록 유도하여 데이터를 수집하기 위함입니다. 홈 화면 배너를 통해 작성 대상자에게 직관적인 UI를 제공하고 작성 페이지로의 접근성을 높이고자 했습니다.
