## 요약
Cloudflare Workers에 스테이징 배포 환경을 추가하기 위해 설정 파일을 업데이트한 PR입니다. `student`, `admin`, `company` 서비스의 `wrangler.jsonc` 파일에 `staging` 환경 설정을 각각 추가하였습니다. 해당 환경은 `develop` 브랜치를 배포하며, Sentry 연결 없이 스테이징 API 서버를 바라보도록 구성되었습니다.

## 변경 내용
- `apps/student/wrangler.jsonc`, `apps/admin/wrangler.jsonc`, `apps/company/wrangler.jsonc` 파일에 `staging` 환경 설정 추가 (`env.staging.name` 값을 `<app>-stag-v2` 형태로 설정)
- Wrangler 배포 시 특정 환경을 타깃할 수 있도록 배포 명령어 설정 적용 (`npx wrangler deploy --config apps/<app>/wrangler.jsonc --env staging`)
- 스테이징 환경의 배포가 스테이징 API 서버(`stag.jobis-dsm.kr`)를 타깃하도록 정의하고 Sentry 토큰 연동은 비활성화 처리

## 의도
운영 환경(`*-v2`)과 일관된 방식으로 스테이징 환경을 Cloudflare Workers에 배포하고 관리하기 위함입니다. 실서비스에 배포하기 전 `develop` 브랜치의 작업본을 독립된 스테이징 서버 환경에서 안전하게 검증하기 위한 목적을 가집니다.
