## 요약
어드민 모집의뢰서 목록의 기간 필터에서 '상시모집' 선택 시 필터링이 동작하지 않던 버그를 수정했습니다. 백엔드 API에 상시모집 필터링 파라미터가 없어 클라이언트 측에서 모집시작일과 종료일이 모두 없는 공고를 걸러내도록 처리했습니다. 또한 필터 상태를 URL 쿼리 파라미터(`constant=true`)로 관리하여 새로고침 시에도 동일한 조회 결과가 유지되도록 만들었습니다.

## 변경 내용
- 기간 필터에서 상시모집 선택 시 URL 쿼리 파라미터에 `constant=true`를 기록하고 서버에는 날짜(start·end) 요청 값을 전달하지 않도록 변경
- 응답받은 공고 데이터 중 모집시작일과 종료일이 없는 공고만 클라이언트 단에서 필터링하여 노출
- 기간 드롭다운에 `checked` 속성을 전달하여 URL 상태에 맞춰 드롭다운 UI에 `상시모집` 표시 상태 동기화
- 클라이언트 단 필터링 적용 중에는 전체 수량 불일치를 방지하기 위해 `총 N개` 표기를 숨기고, 검색 결과 없음 안내 문구를 "선택한 조건"으로 수정

## 의도
어드민 모집의뢰서 목록에서 상시모집 필터를 선택하더라도 드롭다운의 `isConstant` 값이 전달되지 않아 빈 날짜 값으로 전체 목록이 조회되던 버그를 해결하기 위함입니다. 백엔드 API(`GET /recruitments/teacher`)에 상시모집 전용 조건이 없는 한계를 클라이언트 사이드 필터링으로 보완했습니다.
