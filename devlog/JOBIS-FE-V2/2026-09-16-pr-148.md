# 2026-09-16

## 요약
후속 페이지 개발(admin, student 등)에 필요한 디자인 시스템(DS) 공통 컴포넌트의 변경 사항을 한데 모아 반영한 PR입니다. 파일 업로드(`FileUpload`) 컴포넌트를 신규 추가하고 기존 입력창, 텍스트 영역, 파일 다운로드 컴포넌트의 기능과 스타일을 보완했습니다. 또한 유닛 테스트 실행 환경을 구축하고 순환 참조 및 폰트 상속 버그를 해결했습니다.

## 변경 내용
- **FileUpload 컴포넌트 신규 추가**: 라벨, 아이콘, 너비 조절, 비활성화 상태를 지원하는 파일 업로드 버튼 컴포넌트와 스토리북 및 유닛 테스트를 추가했습니다.
- **FileDownload 컴포넌트 기능 개선**: 파일 목록에서 선택적으로 아이템을 삭제할 수 있는 삭제 버튼을 추가했습니다.
- **Input 및 TextArea 스타일 추가**: 버그 제보 페이지 등에서 활용할 수 있도록 밑줄(`underline`) 및 `filled` 변형(Variant) 스타일을 추가했습니다.
- **글로벌 및 레이아웃 수정**:
  - `Container` 컴포넌트가 가로 방향으로 자동 중앙 정렬되도록 개선했습니다.
  - `GlobalStyles`를 수정하여 `input`, `textarea`, `button` 등 폼 요소들이 서비스 기본 글꼴을 일관되게 상속받도록 처리했습니다.
- **테스트 및 접근성 개선**:
  - `vitest.unit.config.ts` 및 관련 셋업 파일을 추가하여 디자인 시스템의 독립적인 유닛 테스트 실행 구조를 마련했습니다.
  - `ListSection` 내 전체보기 버튼에 접근성 속성을 추가하고, 미사용 컴포넌트 검사 및 예전 사양의 테스트 코드를 제거했습니다.

## 의도
이후 개발 예정인 admin 및 student 페이지 작업(스택 PR로 구성됨)이 해당 공통 컴포넌트에 의존하고 있으므로, 디자인 시스템의 변경 사항을 먼저 안전하게 검증하고 병합하기 위함입니다.

## 트러블 슈팅
- **컴포넌트 간 순환 참조 발생** → `Modal.tsx` 내에서 순환 참조를 일으키던 부분을 파악하여 모듈 참조 구조를 정리했습니다.
- **폼 요소의 기본 글꼴 미상속 문제** → 브라우저 기본 스타일로 인해 `input`이나 `textarea`에 웹 서비스 폰트가 상속되지 않던 현상을 `GlobalStyles` 전역 선언(`font-family: inherit`)을 통해 일괄 해결했습니다.
- **오래된 유닛 테스트 실패 우려** → 기능이 제거되거나 명세가 바뀐 기존 컴포넌트(`CompanyCard`, `RecrutementCard` 등)의 유닛 테스트 코드에서 더 이상 유효하지 않은 검증 로직을 찾아내어 정리했습니다.
