## 주요 변경 사항
- (AD) 기업 상세 매출액 "억", 근로자 수 "명" 단위 표시
  - 백엔드는 `double take`만 주지만, 어드민 기업 목록 헤더 "매출액(억)", 학생 웹, iOS·Android 모두 억 단위로 다루고 있어 맞췄습니다.
- (AD) 기업 수정에서 저장 시 실제로 검사하는 필수 항목에 `*` 표시
- (AD) 공지 상세 회색 배경(grayScale/30), 작성·수정 회색 배경(grayScale/20), 시안 픽셀 기준
  - 레이아웃 `<main>`에 전체 너비(`width: 100%`, `minWidth: min-content`)와 `display: grid` 적용
  - 회색 배경이 푸터까지 차고, 창이 표보다 좁아도 왼쪽이 잘리지 않습니다.
  - 목록·기업 상세·준비 중·공지 상세 구조를 1440px·1100px에서 측정했습니다. 내용물 좌표는 변경 전과 같았습니다.
- (AD) 공지 번호를 DB id 대신 "최신 글이 가장 큰 번호"로 표시 (학생 공지 목록과 같은 규칙)
  - `/notices/count`가 페이지 수만 줘서 마지막 페이지 글 수로 전체 개수를 계산합니다.
  - 받는 중이나 어긋난 경우는 "-", 요청 실패 시 id
  - 페이지 크기는 `@jobis/api`의 `NOTICE_LIST_PAGE_SIZE` 사용
- (DS) 푸터 저작권 연도를 시안대로 `©2023` 고정 (이메일은 #177에서 정한 jobis@dsm.hs.kr 유지)
- (DS) Dropdown·PeriodDropdown 접근성·키보드 (props/API 변경 없음)
  - Escape로 닫기 (한글 조합 중·이미 처리된 이벤트는 제외), 드롭다운 안에 있던 초점은 트리거로 복귀
  - 트리거 `aria-haspopup`·`aria-expanded`·`aria-controls`, 목록 `role="listbox"` + `aria-labelledby`, 항목 `role="option"` + `aria-selected`
  - 로빙 tabindex, ArrowUp/Down·Home·End 이동, Enter/Space 선택, Tab으로 벗어나면 닫힘, 트리거에서 ArrowDown으로 열기
  - 아이콘 이름이 버튼 이름에 섞이던 문제("상태변경ChevronDown") 수정
  - 기간 초기화·닫기 아이콘을 이름 있는 버튼으로 변경, 달력만 닫을 때 초점을 달력 버튼으로 복귀
