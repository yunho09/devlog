## 주요 변경 사항
- (AP/DS/ST) 지원 불가 표시
  - 상세 타입에 `unapplicable_reason` 추가 (ALREADY_APPLIED / NOT_RECRUITING / HAS_ACTIVE_APPLICATION / GRADE_NOT_ELIGIBLE)
  - 상세 헤더 "지원하기" 비활성 + 사유 표시 (`applyDisabledReason`, `aria-describedby` 연결)
  - 지원 페이지에 주소로 바로 들어와도 같은 이유로 막힘
  - 지원 성공·지원 취소 후 모집의뢰서 상세 전체를 다시 조회 (`HAS_ACTIVE_APPLICATION`은 모든 공고에 걸리기 때문)
- (ST) 지원 실패 문구
  - 401 → "지원 가능한 학년이 아닙니다." (겨울인턴은 2학년 대상이라 "3학년만"은 틀린 안내였습니다)
  - 409 → "이미 지원했거나 진행 중인 다른 지원이 있습니다." (백엔드가 같은 공고 재지원과 올해 진행 중인 지원을 같은 409로 줍니다)
  - 400(모집중이 아님 포함) 문구 수정
  - 성공 후 이동 전까지 버튼 잠금 (중복 제출 방지)
- (ST) 지원하기 카드가 왼쪽에 붙던 문제 수정 (고정 780px Box → `Container $maxWidth`)
- (AP/DS/ST) 모집의뢰서 카드에 겨울인턴 칩 (`winter_intern`, BE #1158)
  - 칩 줄바꿈 방지. 칩이 3개일 때만 간격 4px로 줄입니다. "모집 종료"+"병역특례 O"+"겨울인턴"이 12px 간격이면 카드 밖으로 넘칩니다.
- (ST) 모집의뢰서 목록 겨울인턴 필터를 서버에 전달
  - 전에는 `winter_intern`이 서버에 전달되지 않았습니다.
  - `status=WIN_INTERN`은 서버로 보내지 않고 `winter_intern=true`만 보냅니다.
- (DS) 카드 직무명 한 줄 말줄임, 북마크와 간격 8px
- (AP/ST) 모집의뢰서 목록 정렬 드롭다운 (시안 12706:11549)
  - 옵션: 기본순·매출·직원↓·직원↑·공고마감↓·공고마감↑
  - 학생 목록에 기업용 `ListSortType`을 쓰고 있어서 `RecruitmentSortType`을 추가했습니다.
  - 정렬 값은 `utils/constants.ts` 한 곳에서 정의합니다.
- (AP/ST) 마이페이지 재지원 연결: `/recruitment/detail/:id/apply?application-id=:id`에서 지원 폼을 재지원 모드로 열고 `PUT /applications/{id}`로 보냅니다.
  - REQUESTED·REJECTED만 허용, 지원 내역을 확인하기 전에는 버튼이 막힙니다.
- (AP) 반려 요청 본문 `rejectionAttachments` → `rejection_attachments`
