## 주요 변경 사항
- (AD) 겨울인턴
  - 상태 변경 옵션(`RECRUITMENT_STATUS_CHANGE_OPTIONS`)에서 겨울인턴 제외
  - 필터에서 겨울인턴을 고르면 `status=WIN_INTERN` 없이 `winter_intern=true`만 전송 (전에는 둘 다 보내서 상태가 덮어써진 공고만 나왔습니다)
- (AP/AD) 모집의뢰서 목록에 `winter_intern` 표시 (상태 칸 아래 "겨울인턴")
- (AD/DS) 서버 페이지네이션 (#172)
  - 모집의뢰서·기업 목록에 `page` 전달, 클라이언트 재분할 제거
  - 페이지 수는 `/teacher/count`, 총 개수는 `/count` 사용
  - 범위 밖 page는 마지막 페이지로 이동
  - Pagination 노출 번호 3 → 5, 현재 페이지가 범위를 넘으면 마지막 묶음 표시
- (AD) 지원서 목록
  - 백엔드 `GET /applications`에는 page가 없고 전체를 돌려줍니다. 그래서 클라이언트 페이지를 유지하고 한 페이지를 10건으로 맞췄습니다.
  - "형태" 칸에 "파일"이 찍히던 문제 수정 → 체험형(겨울인턴)/채용형 표시, 형태 필터 추가
    - 목록 응답에 `winter_intern`이 없어서 같은 년도에 `winter_intern=true` 요청을 한 번 더 보내 구분합니다. 응답에 필드가 추가되면 지울 수 있습니다.
  - 모집의뢰서 목록의 지원요청 수를 해당 모집의뢰서의 접수완료 지원서 목록 링크로 연결 (`recruitment-id`를 API에 전달)
- (AD) 로딩 중 "총 -개" 깜빡임 제거 (이전 결과 유지, 첫 응답 전에는 숨김)
- (AD) 실패 토스트에 상태 코드별 이유 표시 (`getErrorMessage`), 화면별 문구 지정 가능
- (AD) 선도기업 등록이 `LEADING`을 보내 항상 400이던 문제 수정 → `LEAD`, 요청 타입도 `CompanyType`으로 좁힘
- (AD) 모집의뢰서 목록 시안 반영: 헤더 "채용직군", 인원 "N명", 기간 필터 한쪽 날짜만 골라도 표시
- (AD) 구분 필터는 서버 파라미터가 없어 현재 페이지 안에서만 거릅니다. 결과가 0줄이면 안내 문구를 보여 주고 페이지네이션을 유지하며, 구분을 고른 동안에는 "총 N개"를 숨깁니다.
- (AP) `useUpdateTrainDate` 요청 필드를 snake_case로 수정
- (AD) 목록 loader와 화면의 page 파싱 통일
