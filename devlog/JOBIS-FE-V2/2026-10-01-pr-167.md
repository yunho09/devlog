# 2026-10-01

## 요약
JOBIS-FE-V2 프로젝트의 v2 스테이징 QA 과정에서 도출된 13건의 UI/UX 및 기능 버그를 해결한 PR입니다. 스튜던트 및 어드민 웹 서비스 전반의 레이아웃 붕괴 현상을 막고 에셋 경로 매핑, 캐시 설정, 미구현 페이지 안내 라우트 등을 보완하여 서비스 완성도를 높였습니다.

## 변경 내용
- **스튜던트 (ST)**
  - **이미지 경로 복구**: API에서 반환하는 로고 및 프로필 이미지 상대 경로(`LOGO_IMAGE/...`)에 `toFileUrl` 헬퍼 함수를 사용하여 도메인 주소가 붙은 전체 URL로 노출하도록 수정.
  - **문구 줄바꿈 수정**: 기업 및 채용공고 목록에서 "검색된 기업이 없습니다." 문구가 좁은 영역에서 비정상적으로 줄바꿈되던 현상 해결.
  - **준비 중 페이지 도입**: 아직 미구현 상태인 후기 메뉴(`/review/*`) 접근 시 빈 화면 대신 "준비 중인 기능입니다." 안내 화면이 뜨도록 라우터 및 Preparing 페이지 추가.
  - **공지사항 번호 매기기**: DB의 기본 키(ID)를 그대로 보여주던 공지사항 번호를 최신순 정렬에 맞춘 순번 형식(전체 개수부터 1까지 역순)으로 계산하여 노출하도록 변경.
  - **최신성 보장**: 홈 화면 진입 시 노출되는 '최근 본 기업 목록'의 React Query `staleTime`을 `0`으로 재설정하여 캐시 대신 즉시 새로고침 조회하도록 수정.
  - **레이아웃 개선**: 모집의뢰서 목록과 페이지네이션 컴포넌트 사이에 40px 여백을 추가하고, 콘텐츠 길이가 짧은 페이지에서 푸터가 바닥 위로 붕 뜨지 않도록 레이아웃의 최소 높이(`min-height: 100vh`)를 지정.

- **어드민 (AD)**
  - 스튜던트 웹과 마찬가지로 화면 내 콘텐츠가 적을 때 푸터가 위로 끌려 올라가는 현상을 방지하고자 레이아웃에 `min-height: 100vh` 적용.

- **디자인 시스템 (DS)**
  - **Footer**: 깃허브 아이콘 클릭 시 새 창에서 Team-return 공식 저장소로 이동되도록 링크를 추가하고 관련 테스트 코드 작성.
  - **CompanyCard**: 가로 한 행에 카드가 3개 미만으로 렌더링될 때 카드의 너비가 비정상적으로 벌어지지 않고 내부 콘텐츠 크기에 고정되도록 정렬 변경.
  - **Dropdown**: 분야 옵션 개수가 많을 때 드롭다운 박스 영역을 이탈하지 않도록 최대 높이를 320px로 제한 및 스크롤을 적용하고, 기술 스택 태그 선택 영역도 내부 스크롤만 동작하게 구조 변경.
  - **Bookmark**: 텍스트가 늘어나 자리가 좁아져도 북마크 아이콘의 크기가 작아져 찌그러지지 않도록 `flex-shrink: 0` 설정.
  - **RecrutementCard**: 채용 직무명 텍스트가 지나치게 길 경우 카드 레이아웃 유지를 위해 최대 2줄까지만 노출하도록 말줄임 처리를 하고, 마우스오버 시 전체 명칭을 툴팁으로 제공하도록 수정.

## 트러블 슈팅
- **문제**: API가 전달하는 기업 로고 이미지 데이터가 상대 경로(`LOGO_IMAGE/...`) 형식으로 유입되어 스튜던트 페이지에서 엑스박스로 뜨거나 이미지가 누락됨.
  - **해결**: 이미지 경로 파싱부 혹은 컴포넌트 호출 시점에 `toFileUrl` 유틸리티 함수를 적용하여 서버 호스트 주소가 포함된 유효한 URL로 가공하여 매핑했습니다.
- **문제**: 마이페이지처럼 화면에 들어차는 내용물이 적은 뷰에서 푸터가 화면 최하단이 아닌 뷰포트 중간에 붕 떠서 시각적 불일치가 발생함.
  - **해결**: 스튜던트와 어드민의 공통 페이지 레이아웃 컨테이너에 `min-height: 100vh` 스타일을 적용하여, 본문 콘텐츠의 양과 무관하게 푸터가 항상 화면 바닥에 안정적으로 안착하도록 보완했습니다.
- **문제**: 직무명이 예상치를 초과해 길게 기입되는 상황에서, Flex 영역 안의 북마크 아이콘 너비가 텍스트에 밀려 찌그러지는 현상이 생김.
  - **해결**: 아이콘 컨테이너 스타일에 `flex-shrink: 0`을 명시적으로 추가하여 주변 텍스트 길이의 압박에도 정형화된 아이콘 가로 세로 비율을 강제로 고정시켰습니다.
