# 2026-09-22

## 요약
이전 PR(#160)에 작성된 Copilot 리뷰 코멘트 21건을 검증하고, 이 중 실제 결함에 해당하는 16건을 수정한 작업입니다. UI 컴포넌트의 웹 접근성 및 키보드 조작성을 강화하였고, 잘못된 타입 의존성 제거와 쿼리 유효성 검사를 추가했습니다. 아울러 Node 22+ 환경에서 발생하던 디자인 시스템의 유닛 테스트 환경 결함을 폴리필을 통해 해결했습니다.

## 변경 내용
- **타입 의존성 제거**: 디자인 시스템(`@jobis/design-system`)에서 API 패키지의 빌드 산출물(`dist/enum.d`)을 참조하던 지원 상태 타입을 내부에서 자체 정의하도록 변경했습니다.
- **MIME 타입 수정**: HTML 내 favicon의 MIME 타입을 SVG 형식에 맞게 `image/svg+xml`로 정정했습니다.
- **데이터 검증 강화**: 기업 상세 조회, 기업 수정, 면접 후기 등의 로더 페이지 진입 시 ID 파라미터의 양의 정수 여부를 검증하고, `Number.isFinite`를 적용해 무한대(`Infinity`) 값이 전달되는 현상을 방지했습니다.
- **API 요청 안정화**: 인증 코드 확인 시 파라미터가 정상적으로 인코딩되도록 axios `params`로 형식을 바꿨으며, 타임아웃 이벤트 발생 시 `config.onTimeout` 콜백이 누락 없이 호출되도록 조치했습니다.
- **접근성 개선**: `IconButton`, `EmploymentRateBanner` 컴포넌트의 마크업을 실제 `button` 태그로 수정하고, 지원 상태 메뉴에 키보드 조작 및 `aria-controls` 웹 접근성 속성을 추가했습니다.
- **아이콘 및 스타일 수정**: SVG 아이콘의 기본 `fill` 속성을 `currentColor`로 주입받도록 하여 외부 `color` 명세가 정상 작동하게 수정했습니다.
- **오타 정정**: 기존에 존재하던 `onCancle` 프로퍼티 명칭을 `onCancel`로 변경했습니다.

## 의도
이전 코드 리뷰에서 발견된 잠재적 안정성 리스크(쿼리 인코딩 에러, 유효하지 않은 숫자 유입, 타임아웃 처리 누락)를 보완하고, 컴포넌트의 시맨틱 태그 및 ARIA 속성 보완을 통해 웹 접근성 표준을 준수하기 위함입니다. 또한, 로컬 개발 환경에서 테스트 코드가 정상적으로 실행될 수 있도록 보장하고자 했습니다.

## 트러블 슈팅
- **문제**: Node 22+ 환경에서는 전역 `localStorage`를 직접 선점하지만 `--localstorage-file` 플래그 없이는 값이 비어 있는 상태가 됩니다. 이로 인해 Vitest의 jsdom 환경에서 전역에 이미 존재하는 키를 옮기지 않아 jsdom Storage가 제대로 주입되지 않았고, 디자인 시스템 패키지의 단위 테스트가 정상적으로 구동되지 않고 실패하는 현상이 존재했습니다. (CI에서는 단위 테스트를 돌리지 않아 감지되지 못함)
- **해결**: `vitest.unit.setup.ts` 환경 설정 단계에서 Node 22+ 환경을 체크하는 수동 `localStorage` 폴리필 구문을 삽입하여 가상 돔 환경 내 전역 주입을 강제했습니다. 이 개선을 통해 로컬 단위 테스트 272건이 정상 복구되어 모두 통과하게 되었습니다.
