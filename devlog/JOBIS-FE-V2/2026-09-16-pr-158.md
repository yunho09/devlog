## 요약
학생 헤더의 알림 드롭다운에 실제 알림 목록 API(`GET /notifications`)를 연동했습니다. 비동기로 알림 데이터를 가져올 때 신규 알림 표시(빨간 점)가 갱신되지 않던 문제를 해결하고 관련 유닛 테스트를 추가했습니다.

## 변경 내용
- **API 훅 내보내기**: `@jobis/api` 패키지 인덱스에 빠져 있던 `useNotificationList` 등 알림 관련 훅의 export를 추가했습니다.
- **새 알림 표시 갱신 로직 수정**: `StudentHeader`에서 신규 알림 여부(`isNew`)를 첫 렌더링 시점에만 계산하여 비동기 데이터 로드 시 빨간 점이 표시되지 않던 오류를 수정했습니다. 이제 `notifications`가 변경될 때마다 다시 계산합니다.
- **데이터 연동 및 테스트**: 학생 앱 헤더에 `useNotificationList()`의 조회 결과를 연동하고, 갱신 로직이 정상 작동하는지 확인하는 유닛 테스트를 작성했습니다.

## 의도
비동기로 가져오는 알림 목록 데이터에 맞춰 헤더의 신규 알림 상태가 지연 없이 화면에 정확하게 반영되도록 하기 위함입니다.

## 트러블 슈팅
- **문제**: 학생 헤더 컴포넌트가 처음 렌더링될 때만 새 알림 여부(`isNew`)를 평가하여, 비동기 API 요청으로 알림 데이터가 나중에 로드되는 경우 알림이 있어도 헤더에 신규 알림을 나타내는 빨간 점이 표시되지 않는 현상이 있었습니다.
- **해결**: `StudentHeader` 내에서 `notifications` 배열 자체의 변경을 감지하도록 의존성을 보완하여, API 데이터가 도달하는 시점에 `isNew` 상태가 실시간으로 재계산되도록 수정했습니다.
