# 2026-11-24

## 요약
회원가입 과정의 이메일 인증 코드 발송/검증 및 최종 가입 API를 연동했습니다. 가입 성공 시 자동으로 로그인 처리하여 Overview 페이지로 이동하며, 아이디 중복·인증 만료 등 다양한 서버 에러에 대응하는 예외 처리 UX를 구현했습니다. 또한 `@xquare/api` 패키지에 관련 API와 테스트 코드를 추가하고 폼 유효성 검증 규칙을 보완했습니다.

## 변경 내용
- 이메일 인증코드 발송 및 검증 API (`/auth/email/otp`, `/auth/email/otp/verify`) 연동
- 이메일 검증 토큰을 사용한 회원가입 API (`/auth/signup`) 연동 및 성공 시 로그인 상태로 Overview 이동
- 서버 에러별 맞춤 UX 처리 구현:
  - 아이디 중복 시 3단계 아이디 입력 칸으로 안내
  - 인증 시간 만료 시 기존 입력값 유지 상태로 이메일 인증 재진행 안내
  - 이미 가입된 이메일 또는 가입 성공 후 로그인 정보 저장 실패 시 로그인 링크 안내
- API 요청 중 버튼/입력 잠금 처리 및 화면 이탈(unmount) 시 진행 중인 요청 취소 로직 추가
- 비밀번호(ASCII 8~20자, 영문·숫자 외 문자 포함) 및 이름(최대 10자) 유효성 검증 규칙 수정
- 비활성화된 링크 버튼 표상 및 입력 레이아웃 스타일 개선
- `@xquare/api`에 인증/가입 연동 함수 추가 및 단위 테스트 구현

## 의도
이메일 인증 기반의 회원가입 플로우를 완성하고, 이탈 없이 연속적으로 로그인까지 이어지는 사용자 경험을 제공하기 위함입니다. 또한 가입 과정에서 발생할 수 있는 여러 에러 상황에 맞춰 입력 데이터를 보존하거나 적절한 단계로 유도하여 사용자 불편을 줄이고자 했습니다.

## 트러블 슈팅
- 문제: 회원가입 API 요청이 서버에서 처리되어 계정은 생성되었으나, 클라이언트 측 로그인 정보 저장 단계에서 오류가 발생할 경우 사용자가 다시 가입을 시도하다 에러를 겪는 문제
- 해결: 가입 처리 후 로그인 정보 저장만 실패한 특정 상황을 감지하여, 재가입 시도 대신 로그인 페이지로 이동하도록 흐름을 변경함 (`20a5387`)
