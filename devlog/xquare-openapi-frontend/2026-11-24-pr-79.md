# 2026-11-24

## 요약
API 테스트 콘솔에서 입력한 요청을 실제 서버로 전송하고 결과를 확인할 수 있는 기능을 구현했습니다. 요청 상태, 소요 시간, 응답 데이터 크기, 헤더, cURL 복사 기능 및 호출 히스토리 표시를 지원합니다. 요청 진행 중 예외 상황(타임아웃, 취소, 화면 이탈 후 재진입 문제)에 대한 안정성도 함께 보완했습니다.

## 변경 내용
- API 테스트 콘솔에서 실제 서버로 API 요청 전송 기능 구현 (`X-API-KEY` 선택 적용, 포털 토큰 미포함)
- 응답 상태 코드, 소요 시간, 응답 크기, 응답 본문 및 헤더 정보 표시 UI 추가
- cURL 명령어 생성 및 복사 기능, 호출 히스토리 저장 기능 추가
- CORS 등 네트워크 실패 시 '연결 실패' 안내 표기 및 인증 카드 안내 문구 업데이트
- 기본 테스트 예시를 인증 키 없이 호출 가능한 `GET /meals` (startDate, finishDate)로 변경
- 요청 취소 및 시간 초과(Timeout) 처리와 일반 오류 구분 로직 추가
- 요청 진행 중 화면을 이탈했다 돌아왔을 때 재요청이 불가능하던 상태 제어 문제 수정

## 의도
개발자와 사용자가 외부 도구 없이 웹 콘솔에서 직접 API를 테스트하고 cURL 및 응답 결과를 손쉽게 확인할 수 있도록 하기 위함입니다. 또한 네트워크 오류나 사용자 이탈 같은 예외 상황에서도 콘솔 상태가 올바르게 복구되도록 안정성을 확보하고자 했습니다.
