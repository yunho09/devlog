## 요약
API 테스트 페이지의 기본 예시를 `POST /auth/login`에서 `GET https://open.xquare.app/students`로 변경했습니다.
GET 요청 특성에 맞춰 기본 탭을 Params로 전환하고 `grade` 및 `classNum` 입력 폼과 URL 간의 양방향 동기화를 구현했습니다.
또한 JSON 본문 입력 지원, GET 요청 시 Body 탭 비활성화, 조건부 `Content-Type` 헤더 포함 등 UI 및 동적 로직을 개선했습니다.

## 변경 내용
- API 테스트 기본 예시 요청을 `POST /auth/login`에서 `GET https://open.xquare.app/students`로 변경
- 요청 카드 기본 탭을 Params로 변경하고 `grade`, `classNum` 입력 항목 추가
- 쿼리 파라미터 입력 폼과 URL 간 양방향 연동 구현 (유효하지 않은 URL 시 입력 폼 비활성화)
- Body 탭 입력 방식을 기존 ID/비밀번호 입력에서 JSON 본문 직접 입력으로 변경 (GET 요청 시 입력 막음)
- 본문 데이터가 존재하는 경우에만 Headers 및 cURL 복사 텍스트에 `Content-Type` 포함
- 응답 예시 데이터 및 API 호출 히스토리를 `/students` 기준으로 변경

## 의도
PR 정보 기준으로는 기존 POST 기반 테스트 예시보다 활용도가 높은 학생 목록 조회(`GET /students`) 예시를 기본값으로 변경하고, GET 요청의 특성(쿼리 파라미터 사용, Body 미사용)에 맞는 직관적인 UX 및 cURL/헤더 생성 환경을 제공하기 위해 작업했습니다.
