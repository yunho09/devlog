## 요약
비밀번호 찾기 기능의 이메일 인증 코드 발송, 검증 및 비밀번호 재설정(`POST /auth/password/reset`) API를 연동했습니다. `@xquare/api` 패키지에 `auth.resetPassword` 메서드를 추가하고 관련 단위 테스트를 작성했습니다. 재설정 완료 후 로그인 페이지로 이동할 때 변경 완료 안내가 정상적으로 노출되도록 UI 로직을 보강했습니다.

## 변경 내용
- `@xquare/api` 패키지에 비밀번호 재설정 메서드(`auth.resetPassword`) 추가 및 테스트 코드 작성
- `forgot-password-form.tsx`에 인증코드 발송·검증, 비밀번호 재설정 API 연동 및 상태 관리(요청 중 잠금/취소, 재발송, 인증 만료 시 1단계 이동 등) 구현
- `login-form.tsx`에 비밀번호 변경 성공 후 이동해 왔을 때 안내 메시지를 화면에 노출하는 로직 추가
- 인증 폼 공통 스타일(`auth-style.ts`) 추가 및 내보내기 모듈(`index.ts`) 정비

## 의도
비밀번호를 잊은 사용자가 이메일 인증 절차를 거쳐 안전하게 새 비밀번호를 재설정할 수 있도록 전체 유저 플로우를 연결했습니다. 기존 회원가입 폼과 동일한 사용자 경험(중복 입력 방지, 칸별 에러 처리 등)을 제공하여 UX 일관성을 확보하고자 했습니다.
