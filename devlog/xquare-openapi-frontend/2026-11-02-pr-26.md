## 요약
비밀번호 찾기 페이지(`/forgot-password`)의 3단계 퍼블리싱을 진행하고 로그인 페이지와 연결했습니다. 
로그인 화면의 비밀번호 찾기 버튼을 실제 이동 링크로 변경하고 사이드바가 없는 전체 화면 레이아웃에 포함했습니다. 
회원가입 기능의 검증 로직과 스타일을 재사용하여 단계별 입력 폼을 구성했습니다.

## 변경 내용
- `/forgot-password` 경로 및 3단계 폼 컴포넌트(`forgot-password-form.tsx`, `page.tsx`) 추가
  - 1단계: 이메일 입력 및 인증코드 검증
  - 2단계: 학번 및 이름 입력
  - 3단계: 새 비밀번호 설정 및 로그인 이동
- `AppLayout.tsx`의 `FULL_SCREEN_PATHS`에 `/forgot-password`를 추가하여 풀스크린 레이아웃 적용
- `login-form.tsx`에서 기존 `PasswordHelpButton`을 `/forgot-password`로 이동하는 `PasswordHelpLink`로 교체
- `auth-style.ts` 및 `index.ts` 내 인증 관련 컴포넌트 내보내기/스타일 수정

## 의도
비밀번호를 잊어버린 사용자가 단계별 인적사항 및 이메일 인증을 거쳐 새 비밀번호로 변경할 수 있도록 UI 흐름을 제공하기 위함입니다. 기존 회원가입 페이지와 동일한 입력 규칙 및 디자인 패턴을 유지하기 위해 공통 스타일과 검증 로직을 재사용했습니다.
