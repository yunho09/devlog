# 2026-11-10

## 요약
admin 서비스의 관리자 로그인(`/login`) 및 권한 없음(`/forbidden`) 페이지 UI를 퍼블리싱하고 공통 인증 레이아웃(`auth-layout`)을 신규 추가했습니다.
인증 페이지 영역에서는 사이드바를 숨기도록 레이아웃을 처리하고, 기존 사이드바가 긴 페이지 스크롤 시 끊기던 현상을 `sticky` 기반 레이아웃으로 개선했습니다.
또한 배포 과정에서 주요 환경 변수가 누락되지 않도록 `next.config.ts`에 빌드 시점 검증 로직을 도입했습니다.

## 변경 내용
- **관리자 로그인(`/login`) 화면 구현**: 아이디 및 비밀번호 입력 폼 validation(모두 입력 시 버튼 활성화) 및 계정 잠금 안내 문구 추가.
- **권한 없음(`/forbidden`) 화면 구현**: 403 안내 메시지, `/login` 이동 버튼, external Open API 문서 연결 링크 추가.
- **인증 공통 레이아웃(`auth-layout`) 신규 추가**: 1728px 기준 1000px(소개 영역) + 728px(폼 패널) 비율 적용 및 760px 이하 반응형 세로 배치 대응.
- **사이드바 레이아웃 구조 개편**: `/login`, `/forbidden` 경로에서 사이드바 미노출 처리 및 `flex` 열 구조 + `position: sticky` 적용으로 스크롤이 길어져도 사이드바 배경이 끝까지 유지되도록 수정.
- **빌드 타임 환경 변수 검증**: `next.config.ts`에서 `NEXT_PUBLIC_OPEN_API_DOCS_URL` 유효성을 검사하여 누락 시 빌드를 즉시 중단하도록 처리.

## 의도
admin 애플리케이션의 인증 관련 페이지 UI를 구축하고 인증 레이아웃과 기존 대시보드 레이아웃을 명확히 분리하기 위함입니다. 동시에 긴 화면에서 발생하는 사이드바 UI 깨짐 현상을 해결하고, 프로덕션 배포 시 환경 변수 누락으로 발생할 수 있는 런타임 오류를 사전에 차단하고자 했습니다.

## 트러블 슈팅
- **페이지 높이가 긴 화면에서 스크롤 시 사이드바 배경이 뷰포트 높이까지만 그려지고 잘리는 문제** → `AppLayout`과 `sidebar` 구조를 flex 열 형태로 변경하고, 고정 포지셔닝을 `fixed`에서 `sticky`로 변경하여 본문 높이만큼 사이드바 영역이 늘어나도록 해결했습니다.
- **프로덕션 빌드 시 `NEXT_PUBLIC_OPEN_API_DOCS_URL` 환경 변수가 설정되지 않아 기본/로컬 URL을 참조할 위험** → `next.config.ts` 빌드 타임 검증 로직을 추가하여 값이 없거나 빈 문자열일 경우 에러를 던지고 빌드를 멈추도록 수정했습니다.
