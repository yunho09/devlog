어드민 서비스의 공지사항 관리 기능 퍼블리싱을 진행한 PR입니다. 공지 목록 조회, 제목 검색, 글 작성 및 수정 폼, 삭제 확인 모달 컴포넌트를 새로 구축했습니다. 화면 구현을 위한 어드민 색상 토큰과 공지사항 더미 데이터도 함께 추가되었습니다.

## 변경 내용
- **공지 목록 페이지 (`/notice`)**: 제목 검색(검색 버튼 및 Enter 키), 목록 테이블(제목·작성자·작성일시·최종수정·관리), 10개 단위 페이지네이션 및 전체 건수 표시 기능 구현
- **공지 작성 페이지 (`/notice/new`)**: 제목(100자 제한) 및 본문(2000자 제한) 입력 필드 구현, 글자 수 표시 기능과 제목·본문 입력 시에만 저장 가능하도록 유효성 검증 적용
- **공지 수정 페이지 (`/notice/[id]/edit`)**: 기존 데이터 로딩, 변경 사항이 존재할 때만 저장 활성화, 하단 삭제 버튼 제공 및 존재하지 않는 공지 번호 접근 시 404 처리
- **삭제 확인 모달 (`delete-notice-modal.tsx`)**: 공지 삭제 시 되돌릴 수 없는 작업 특성을 고려하여 기본 포커스를 '취소' 버튼에 위치시킨 Danger 모달 구현
- **공통 자원 추가**: 어드민 색상 토큰(`styles/colors.ts`) 및 UI 테스트용 공지 더미 데이터(`notice-content.ts`) 추가

## 의도
어드민 사용자가 공지사항을 효율적으로 작성, 수정, 삭제, 조회할 수 있는 인터페이스를 제공하기 위함입니다. 백엔드 API 연동 전 더미 데이터를 활용해 UI 동작, 페이지네이션, 폼 유효성 검증 상태를 우선 구성했습니다.
