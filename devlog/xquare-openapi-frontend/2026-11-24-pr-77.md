## 요약
Admin 어드민 서비스의 로그인, 로그아웃, 403 권한 없음 라우팅 및 연동 작업을 진행했습니다. 로그인 후 `/users/me`로 ADMIN 권한을 검증하고, 비인가 접근을 차단하며 토큰 삭제 후 `/forbidden`으로 리다이렉트 처리했습니다. 또한 다중 탭 환경에서의 상태 동기화 및 이전 계정 데이터 잔재 문제를 해결하고 내 정보 캐싱 로직을 구현했습니다.

## 변경 내용
- 로그인 성공 시 `/users/me` 경로를 통해 ADMIN 권한을 검증하는 기능 추가 (ADMIN 권한이 없으면 토큰 삭제 후 `/forbidden`으로 이동).
- `/login`, `/forbidden`을 제외한 모든 admin 페이지 접근 시 로그인 및 ADMIN 권한 검증 로직 추가 (검증 전 렌더링 차단).
- 사이드바 사용자 실명 표기 및 로그아웃 연동 처리.
- 403 권한 없음 페이지에 '다른 계정으로 로그인' 기능 추가.
- 내 정보 단일 로딩 및 캐싱을 위한 `my-info.ts` 추가 (로그인, 로그아웃, 탭 변경 시에만 재요청).

## 의도
어드민 서비스 특성상 권한이 없는 사용자의 페이지 접근 및 깜빡임 현상을 원천 차단하여 보안과 UX를 강화하고자 했습니다. 또한 불필요한 내 정보 API 재호출을 줄이기 위해 데이터 캐싱을 도입하고, 다중 탭 이용 시 발생할 수 있는 동기화 오류를 방지하고자 했습니다.
