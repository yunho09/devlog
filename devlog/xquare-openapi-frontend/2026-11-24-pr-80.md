## 요약
Admin 어플리케이션의 공지사항 관리(등록·수정·삭제·목록) API 및 User 어플리케이션의 공지사항 목록(10건 단위 페이징)과 상세 페이지 API를 연동했습니다. 각 앱의 `notice-content.ts`로 응답 데이터 변환 로직을 일원화하고 공지 본문 최대 길이를 4,000자로 늘렸습니다. 연동 후 발생한 이전 에러 상태 누수, 포커스 처리, 폼 초기화 타이밍 등의 에러 상태 및 UI 동기화 문제를 보완했습니다.

## 변경 내용
- **Admin 기능 연동**: 공지사항 목록 조회(GET), 등록(POST), 수정(PATCH), 삭제(DELETE) API 연결, 저장 중 버튼 잠금 및 서버 오류 메시지 표시 처리
- **User 기능 연동**: 공지사항 목록 서버 페이징(페이지당 10건, 이전/다음 버튼) 및 상세 화면 API 연동, 401/404 예외 처리 연결
- **데이터 변환 일원화**: `apps/admin/src/app/notice-content.ts` 및 `apps/user/src/app/notice-content.ts`에서 API 응답을 화면 출력용 값으로 변환하도록 통합
- **입력 스펙 수정**: 공지 본문 최대 입력 길이 제한을 4,000자로 변경
- **상태 처리 보완**: 목록/상세 데이터 재조회 시 기존 에러 화면 제거, 삭제 후 포커스 이동 보완, 수정 폼 저장 시에만 폼 비우도록 변경
