## 요약
유저 및 어드민 웹에서 경력증명서를 일괄 등록할 수 있도록 API 연동 작업을 진행했습니다. 파일 업로드, 자동 매핑, 미리보기 및 등록 완료에 이르는 전체 흐름을 안전하게 제어하는 비즈니스 로직을 구축했습니다. 특히, 네트워크 요청 지연이나 페이지 이탈 등 불안정한 사용자 흐름 속에서도 데이터 정합성을 유지하도록 보완했습니다.

## 변경 내용
- 경력사항 파일 업로드 및 매핑 확정을 위한 API 클라이언트 추가 및 단위 테스트 작성
- 공용 UI 패키지 내 등록 컴포넌트(`IntegratedRegistrationConfirm`, `IntegratedRegistrationPreview`, `IntegratedRegistrationUpload`)에 업로드/제출/에러 상태 표시를 위한 Props 및 스타일 추가
- 어드민 웹(`admin-web`)과 유저 웹(`user-web`)의 통합 등록 페이지에 API 연동 로직 구현
- 등록 세션 상태 관리 및 파일 처리를 돕는 유틸리티(`registrationSession.ts`, `files.ts`) 추가 및 확장
- API 요청 도중 이탈하거나 흐름이 재시작되었을 때 이전 비동기 요청을 명시적으로 무효화하는 예외 처리 도입

## 의도
사용자가 대량의 경력증명서 데이터를 안심하고 일괄 등록할 수 있도록 매끄러운 다단계 흐름을 구현하고자 했습니다. 또한 네트워크 요청이 완료되기 전에 사용자가 취소하거나 다른 페이지로 이동하는 예외 상황에서 불필요한 부작용이나 데이터 왜곡이 발생하지 않도록 비동기 파이프라인의 안정성을 보강하기 위함입니다.

## 트러블 슈팅
- **문제**: 통합 등록 결과를 브라우저 세션 스토리지에 저장하는 데 실패하는 경우, 완료 페이지로의 흐름이 단절되거나 오류가 발생할 수 있음.
  - **해결**: 세션 저장 실패 시 폴백(Fallback) 수단으로 React Router의 state를 활용하여 완료 페이지에 다이렉트로 데이터를 안전하게 넘기도록 구현을 수정했습니다 (`9d46885`).
- **문제**: 파일 업로드 요청 도중 사용자가 파일을 새로 올리거나 작업을 취소하는 경우, 이전 비동기 요청의 응답이 나중에 도달하여 화면 상태를 꼬이게 만들 우려가 존재함.
  - **해결**: 업로드 페이지에서 새로운 등록 시도가 발생하면 즉시 이전 업로드 요청을 무효화 처리하도록 조치했습니다 (`d9d2a43`).
- **문제**: 사용자가 최종 확인을 완료하기 전에 페이지를 이탈하면, 지연되어 실행 중이던 이전 확인 API 요청의 결과가 엉뚱한 맥락에서 유실되거나 중복 저장될 위험이 있음.
  - **해결**: 정상적인 등록 프로세스 흐름에서 완전히 이탈한 경우 해당 요청의 결과를 세션이나 상태에 반영하지 않도록 검증 후 무효화하는 방어 코드를 적용했습니다 (`c324dc6`).
