# 2026-10-06

## 요약
백엔드의 새 경력증명서 서식 개편에 맞추어 프론트엔드의 대체 미리보기 레이아웃과 데이터 산출 로직을 업데이트했습니다. 비엑셀 파일을 잘못 업로드했을 때의 구체적인 변환 안내를 추가하고, 엑셀 일괄 등록 시 주소 매핑 및 신규 인적사항 수 표기 기능을 반영했습니다. 또한, 등록 완료 후 재진입 시 기존 업로드 세션이 남아 새 파일 등록을 방해하던 문제를 해결하고 복원 파일 표시 방식을 개선했습니다.

## 변경 내용
- **대체 미리보기 레이아웃 및 로직 개편**: 백엔드의 신규 경력증명서 서식에 맞추어 레이아웃(제목 밑줄, 한글/영문 성명 세로 배치, 생년월일/주소 가로 배치, 10행 고정 재직사항 등)을 변경했습니다. 총 근무기간 계산 방식(30일=1개월)과 퇴직사유 추출(마지막 이력만 반영) 방식을 백엔드와 동일하게 구현했습니다.
- **비엑셀 파일 대응**: `.xlsx` 확장자만 임의로 바꾼 가짜 엑셀 파일을 감지하여 백엔드에서 `NOT_AN_EXCEL_FILE` 에러를 보낼 시, 사용자에게 Excel 통합 문서로 제대로 저장하여 변환하도록 안내하는 메시지를 출력합니다.
- **엑셀 일괄 등록 확장**: 엑셀 매핑 컬럼에 `address`(주소)를 추가하여 처음 등장하는 대상자의 주소로 저장하도록 했으며, 신규 등록된 인적사항 수(`createdHumanCount`)를 완료 화면에 보여줍니다.
- **업로드 세션 관리 개선**: 엑셀 일괄 등록을 완료한 후 메뉴를 통해 업로드 화면으로 재진입했을 때, 기존의 완료 세션이 남아 새로운 파일 선택을 막지 않도록 세션을 초기화하고 새로 시작하게 변경했습니다.

## 의도
백엔드의 서식 개편 및 신규 비즈니스 요구사항(주소 매핑, 신규 인적사항 카운트, 예외 처리 강화)에 대응하여 프론트엔드 시스템의 일관성을 맞추기 위함입니다. 또한, 사용자가 엑셀 일괄 등록 프로세스를 원활하게 반복해서 완료할 수 있도록 세션 잔류 문제와 파일 형식 복원 시의 UI 문제를 개선하여 사용자 경험을 향상시키고자 했습니다.

## 트러블 슈팅
- **확장자만 바꾼 잘못된 파일 업로드 시 피드백 문제**
  - 문제: 확장자만 `.xlsx`로 우회하여 올린 비엑셀 파일에 대해 일반적인 "지원하지 않는 형식" 에러가 노출되어 사용자가 원인을 정확히 알기 어려움
  - 해결: 백엔드의 `NOT_AN_EXCEL_FILE` (400) 에러 코드를 식별하여 "다른 이름으로 저장 → Excel 통합 문서(.xlsx)" 형태로 올바르게 변환하라는 구체적인 해결 가이드를 화면에 노출하도록 변경함
- **완료 후 화면 재진입 시 업로드 불가 문제**
  - 문제: 일괄 등록을 완료한 후, 다른 페이지로 갔다가 다시 업로드 화면에 진입하면 이전의 완료 세션이 유지되어 새로운 파일을 업로드하려는 시도가 무시되는 현상 발생
  - 해결: 완료 결과가 남아있는 세션인 경우 업로드 화면 컴포넌트 진입 시 기존 상태를 클리어하고 새로 시작하도록 세션 초기화 로직을 추가함
- **세션 복원 파일 정보 표시 오류**
  - 문제: 세션에서 복원한 파일의 상세 데이터가 UI상에서 `[, 0B]` 형태로 깨져서 노출되는 문제
  - 해결: `packages/utils/src/files.ts` 파일 내 포맷팅 함수를 수정하여 복원된 파일 객체의 형식과 크기가 깨지지 않고 정확하게 표시되도록 보완함
