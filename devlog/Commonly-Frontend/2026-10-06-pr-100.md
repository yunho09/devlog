## 트러블 슈팅
- **경력 조회 중 대상자 전환 시의 데이터 혼선 문제**
  - **문제**: 경력을 가져오는 로딩 속도 지연 등의 상황에서, 사용자가 빠르게 대상자를 변경하거나 페이지를 전환할 때 다른 대상자의 경력 정보와 선택 상태가 섞여서 저장되거나 잘못된 에러가 잔존하는 현상 발생.
  - **해결**: 경력을 조회하거나 가공 중일 때는 대상자 선택 UI 자체를 완전히 잠그도록(disabled) 처리하고, 재조회 시 이전의 경력 선택 잔존 상태를 깨끗이 비워주는 가드 로직을 삽입하여 무결성을 보장했습니다 (`8718ee9`, `7286071`, `2704d6d`).

- **동시 발생한 401 에러의 리다이렉트 루프 문제**
  - **문제**: 여러 API가 동시에 호출되어 여러 개의 401 에러가 터질 경우, 로그인 화면으로 가는 `redirectTo` 쿼리가 무한히 중첩되어 쌓이는 문제 발생.
  - **해결**: 라우터의 쿼리를 검사하여 기존에 리다이렉트 흐름이 설정되어 있다면 중복해서 중첩되지 않도록 안전 장치를 설계했습니다 (`ee530dd`).

- **엑셀 재등록 시 이전 파일 상태의 유실 및 고착 문제**
  - **문제**: 엑셀 일괄 등록을 완료한 이후, 사용자가 엑셀 업로드 화면을 다시 열었을 때 이전 세션에서 확정한 파일이 여전히 남아있어 새로운 등록 플로우를 방해하는 현상 발견.
  - **해결**: 모달이나 등록 컴포넌트를 다시 오픈하는 시점에 강제로 임시 상태를 새로고침(reset)하여 항상 신규 파일로 시작되도록 처리하고, 파일의 형식이나 크기 검출 상태를 즉시 초기화하도록 보완했습니다 (`7b23996`).

- **엑셀 매핑 화면의 한글 단어 줄바꿈 및 특수문자 UI 깨짐 문제**
  - **문제**: 엑셀 일괄 등록 매핑 화면에서 가로 공간 부족으로 라벨의 단어 중간이 끊어지거나 필수 표시 별표(`*`)가 다음 줄로 혼자 떨어져 시각적인 완성도가 떨어지는 현상 발생.
  - **해결**: 매핑 라벨의 레이아웃을 드롭다운 선택박스의 윗부분에 넓게 한 줄로 완전히 재배치하여 줄바꿈 및 시각적인 불일치를 일괄 해결했습니다 (`19fb217`).
