# 2026-07-22

## 요약
`apps/civil-web` 서비스의 공통 레이아웃 컴포넌트인 `CivilLayout`에 로그아웃 기능을 추가했습니다. 사용자가 로그아웃을 시도하면 확인 과정을 거쳐 인증 토큰을 삭제하고 로그인 페이지(`/login`)로 리다이렉트합니다. 이 변경을 통해 전역 애플리케이션 헤더에서 일관된 로그아웃 처리가 가능해졌습니다.

## 변경 내용
- **로그아웃 핸들러 구현**: 사용자 확인(Confirmation)을 거쳐 `@commonly/utils` 패키지의 `clearAuthToken`을 호출하고 `/login`으로 리다이렉트하는 `handleLogout` 함수를 구현했습니다.
- **레이아웃 헤더 연동**: `ApplicationShell` 컴포넌트에 전달되는 `headerProps`에 `onLogout` 핸들러로 `handleLogout`을 연결했습니다.

## 의도
사용자가 웹 애플리케이션 내에서 세션을 안전하게 종료할 수 있는 표준 로그아웃 흐름을 제공하기 위함입니다. 공통 레이아웃의 헤더 영역에 로그아웃 액션을 바인딩함으로써, 사용자가 어떤 페이지에 있든 손쉽게 인증을 해제하고 로그인 화면으로 돌아갈 수 있도록 설계했습니다.
