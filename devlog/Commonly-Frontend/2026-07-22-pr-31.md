# 2026-07-22

## 요약
공유 UI 패키지와 Civil Web 앱에 민원인(civil) 사용자 흐름에 맞춘 로그인 페이지와 폼 변형(variant) 기능을 추가하였습니다. 비인증/인증 상태에 따른 라우팅 흐름을 개선하고, `ApplicationShell` 레이아웃에 화면 전체 높이 차지 여부를 조절하는 옵션을 도입하여 화면 구성의 유연성을 확보하였습니다.

## 변경 내용
- **민원인 로그인 변형(Variant) 구현**: 공유 UI의 `Login` 컴포넌트에 `LoginVariant` 타입과 `variant` 프로퍼티('default', 'civil')를 도입하여 모드에 따른 별도 UI 및 스타일 처리를 지원합니다.
- **스타일링 확장**: `login.styles.ts` 파일 내 스타일드 컴포넌트들을 업데이트하여 'civil' 변형에 필요한 레이아웃, 자간, 폰트 크기 및 안내 메시지 영역을 추가로 대응하였습니다.
- **Civil Web 내 로그인 연동**: Civil Web 애플리케이션에 `LoginPage`를 추가하여 민원인 모드로 로그인 폼을 사용하며, 로그인 아이디 기억 및 세션 토큰 제어 로직을 적용하였습니다.
- **인증 기반 라우팅 개선**: `router/index.tsx`에 라우터 로더(loader) 기능을 활용해 로그인하지 않은 사용자는 로그인 페이지로, 이미 인증된 사용자는 로그인 페이지 진입 시 리다이렉트되도록 경로 보호 로직을 보완하였습니다.
- **레이아웃 유연성 확보**: `ApplicationShell` 컴포넌트와 그 스타일에 선택적으로 적용 가능한 `fillViewport` 프로퍼티를 추가하여, 전체 화면 높이를 강제하지 않고 자유로운 스크롤 레이아웃을 구성할 수 있게 하였습니다.
- **의존성 추가**: Civil Web 앱에서 공유 인증/세션 로직 등을 활용할 수 있도록 `@commonly/utils` 패키지 의존성을 명시하였습니다.
