# 2026-10-06

## 요약
실서버 통합 테스트와 화면 점검 중 발견된 다양한 UI 레이아웃 이상 현상과 프론트-백엔드 간 필수 필드 불일치 문제를 한 번에 해결한 PR입니다. 업무 이력 표의 높이 오작동 및 텍스트 줄바꿈 현상을 다듬고, 선택칸의 폰트 색상 일관성을 맞추었습니다. 또한 엑셀 매핑 시 성별 필드를 필수로 강제하여 백엔드 측의 데이터 유효성 에러(400)를 방지했습니다.

## 변경 내용
- **업무 이력 표 레이아웃 수정**: 데이터가 적어도 표 전체 높이(539px)만큼 불필요하게 행이 늘어나지 않도록 하고, 상세 내용(사유)이 길어질 경우 칸 안에서 자동 줄바꿈되도록 스타일을 수정했습니다.
- **엑셀 매핑 필수 항목 명시**: 백엔드 검증 사양에 맞춰 성별 필드를 매핑 필수 항목으로 설정하여, 필수 매핑 누락으로 인한 확정 시점의 `REQUIRED_FIELD_NOT_MAPPED` (400) 에러 발생을 방지했습니다.
- **선택창(Select) 값 선택 시 글자색 변경**: 발급/수정 대상자 조회 등 총 5개 영역의 선택창에서 값을 선택한 후에도 플레이스홀더처럼 흐리게 표시되던 글자색을 일반 텍스트처럼 진하게 보이도록 개선하고, 이를 공통 스타일(`form/formControls.styles.ts`)로 묶어 정돈했습니다.
- **근무 기간 날짜 끊김 현상 방지**: 발급 4단계 경력 표 내의 근무 기간 텍스트가 날짜 중간에서 끊겨 개행되지 않고, `~` 기호 뒤에서만 자연스럽게 줄바꿈되도록 보완했습니다.

## 의도
통합 테스트 도중 실제 백엔드 서버 스펙과 프론트엔드 검증 조건 사이의 간극(성별 필수값 누락)으로 인해 발생하는 API 차단 오류를 사전에 방지하기 위함입니다. 동시에 사용자에게 시각적으로 어색함을 주거나 정보가 잘려 보이는 마이너한 UI/UX 버그들을 전반적으로 보완하여 완성도를 다듬고자 했습니다.
