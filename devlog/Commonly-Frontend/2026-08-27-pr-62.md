# 2026-08-27

## 요약
미연동 상태였던 핵심 화면들에 실제 API 및 외부 서비스를 연동하여 프론트엔드 전반의 기능을 완성했습니다. 도로명주소 API 검색 모달 도입, JWT 기반의 헤더 세션 실시간 갱신, 민원인 본인 경력 조회 및 발급 연동을 구현했습니다. 또한 기존 정적 이미지였던 경력증명서 미리보기를 실제 데이터 기반의 동적 렌더링으로 전환하고, 어드민 경력 등록 라우트를 사용자 화면과 정렬했습니다.

## 변경 내용
- **도로명주소 검색 API 연동**: `business.juso.go.kr` JSONP 검색 방식을 활용한 `searchAddresses` 기능을 추가하고, 대상자 입력 화면의 주소 검색 필드를 검색 모달로 대체하였습니다.
- **헤더 사용자명 및 세션 실시간 연동**: JWT 페이로드에서 이름 관련 클레임 및 만료 시간(`exp`)을 읽어와 표시하고, 1초 단위로 남은 시간을 갱신해 보여주는 `useAuthSession` 훅을 구현했습니다.
- **민원인 본인 경력 조회 연동**: `GET /api/certificates/self` API를 통해 본인의 경력 목록을 불러오고, 선택된 경력 ID들(`certificateIds`)을 전송하여 발급 신청을 완료하는 프로세스를 연동했습니다. 기존의 더미 데이터와 임시 PNG 다운로드 처리는 제거했습니다.
- **경력증명서 미리보기 구현**: 고정 이미지 폴백 방식 대신, 신청 데이터(성명, 생년월일, 선택 경력, 용도, 발급일 등)에 맞춰 실제 문서 형태로 화면에 렌더링하도록 개선했습니다.
- **어드민 경력 등록 라우트 개편**: admin-web의 경력 등록 방식을 user-web과 동일한 흐름(개별 등록 단계 및 통합 등록 미리보기 단계 등)으로 통합 및 구축했습니다.

## 의도
하드코딩되었던 임시 더미 데이터와 정적 리소스를 걷어내고 백엔드 명세 및 외부 API를 실제 연동하여 상용 수준의 서비스 흐름을 확보하고자 했습니다. 공통 사용되는 인증 세션 정보와 주소 검색 유틸리티를 패키지화하여 모노레포 환경 내 여러 서비스(`admin-web`, `civil-web`, `user-web`)의 코드 일관성과 재사용성을 극대화하기 위함입니다.
