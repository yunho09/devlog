# 2026-07-22

## 요약
civil-web 애플리케이션에 사용자 회원가입 흐름을 새로 구현하고 관련 라우트를 추가했습니다. 본인인증 단계를 거쳐 가입 폼으로 이어지는 구조를 설계했으며, 이에 필요한 검증 유틸리티와 단위 테스트를 작성했습니다. 또한 기존 로그인 컴포넌트를 개선하여 회원가입 링크를 동적으로 주입할 수 있게 하고, 경력증명서 발급 페이지의 뼈대를 추가했습니다.

## 변경 내용
- **회원가입 흐름 구현**: 본인인증 패널 및 지원 정보를 포함하는 `SignupPage`와 정보를 입력하는 `SignupFormPage`를 새롭게 추가했습니다.
- **라우터 등록**: `/signup`, `/signup/form` 및 `/career/issue` 경로를 애플리케이션 라우터(`router/index.tsx`)에 새로 등록했습니다.
- **인증 검증 로직 및 테스트**: 생년월일 포맷팅 및 테스트용 인증 처리를 담당하는 `signupVerification.ts` 유틸리티와 이에 대한 단위 테스트(`signupVerification.test.ts`)를 작성했습니다.
- **로그인 컴포넌트 개선**: 공통 UI 패키지의 `Login` 컴포넌트가 `signupHref` props를 받을 수 있도록 수정하여, 로그인 화면에서 회원가입 페이지인 `/signup`으로 이동할 수 있도록 연결했습니다.
- **경력증명서 발급 페이지**: 신규 페이지인 `CareerCertificateIssuePage`를 생성했습니다.

## 의도
사용자가 서비스를 이용하기 위한 필수적인 회원가입 절차를 원활하게 수행할 수 있도록 엔드투엔드 가입 흐름을 마련하고자 했습니다. 공통 UI 컴포넌트인 `Login`에 특정 경로를 하드코딩하지 않고 props(`signupHref`)로 제어하도록 설계하여 멀티 애플리케이션 환경에서의 컴포넌트 재사용성을 높였습니다.
