# 2026-07-22

## 요약
미사용 중이던 KRDS 컴포넌트를 활성화하여 기존 UI 컴포넌트들을 리팩터링했습니다. 또한, 경력사항 등록 등의 페이지 전환 시 화면이 최상단으로 이동할 수 있도록 공통 스크롤 훅을 추가하여 적용했습니다. 추가로 AI 코파일럿의 리뷰 내용을 반영하고 UI 테스트 코드를 새로 작성했습니다.

## 변경 내용
- **KRDS 컴포넌트 적용:** 사용되지 않고 있던 KRDS 컴포넌트들을 적용하여 스타일과 마크업 구조를 리팩터링했습니다.
- **페이지 상단 스크롤 기능 추가:** 페이지가 변경될 때 상단으로 스크롤을 이동시키는 공통 훅 `useScrollToTopOnChange`를 추가하고 `AdminLayout` 및 `UserLayout`에 적용했습니다.
- **기존 스크롤 로직 축소:** 특정 컴포넌트에 종속되어 있던 스크롤 로직인 `useCareerCertificateScroll` 파일의 복잡한 구현을 대폭 덜어냈습니다.
- **UI 코드 최적화:** `IntegratedRegistrationUpload.tsx` 파일 등에서 수십 라인의 불필요한 코드를 정리하여 유지보수성을 높였습니다.
- **테스트 코드 추가:** `integratedRegistration.test.tsx` 파일을 추가하여 관련 UI 동작에 대한 검증 기반을 마련했습니다.
- **리뷰 반영:** 코파일럿 피드백을 기반으로 한 리팩터링 수정 사항을 반영했습니다.

## 의도
통합적인 디자인 시스템 적용(KRDS)을 극대화하여 UI 구성의 일관성을 높이고 중복 구현된 스타일 코드를 정리하고자 했습니다. 또한, 사용자가 긴 폼을 작성하거나 페이지를 전환할 때 스크롤 위치가 유지되어 불편함을 겪지 않도록, 일관된 스크롤 업 동작을 제공하여 사용자 경험(UX)을 향상시키고자 했습니다.
