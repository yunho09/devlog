# 2026-07-22

## 요약
어드민 웹 애플리케이션에 '업무 이력 조회' 기능을 도입하기 위해 관련 UI 컴포넌트와 라우트를 추가했습니다. 공용 UI 패키지(`packages/ui`)에 페이지네이션 및 접근성을 지원하는 `WorkHistory` 테이블 컴포넌트를 구현하고, 어드민 앱의 `/history` 경로에 연결했습니다. 이와 함께 프로젝트 디자인 명세서(`DESIGN.md`)에 신규 페이지 설계 요소를 반영했습니다.

## 변경 내용
- **UI 컴포넌트 구현 및 외부 노출 (`packages/ui`)**:
  - 페이지네이션, 커스텀 네비게이션, 페이지 점프 기능이 포함된 테이블 형태의 `WorkHistory` 컴포넌트 및 스타일 코드(`WorkHistory.styles.ts`) 추가
  - 외부 애플리케이션에서 가져다 쓸 수 있도록 `packages/ui/src/index.ts`에 컴포넌트 및 타입 내보내기 정의 추가
- **어드민 앱 연동 (`apps/admin-web`)**:
  - `WorkHistory` 컴포넌트를 호출하는 `WorkHistoryPage` 생성
  - 라우터(`router/index.tsx`) 내 `/history` 경로의 플레이스홀더를 신규 페이지 컴포넌트로 대체 등록
- **문서화 (`DESIGN.md`)**:
  - 신규 업무 이력 조회 페이지 설계 및 컴포넌트의 반응형/테이블 레이아웃 요구사항 업데이트

## 의도
PR 정보 기준으로는 어드민 사용자가 과거 업무 내역을 페이지 단위로 편리하고 일관되게 조회할 수 있는 전용 지면을 제공하려는 목적입니다. 개별 서비스가 아닌 공용 UI 라이브러리에 테이블과 스타일 컴포넌트를 격리 구현함으로써, 일관된 사용자 경험을 유지하고 향후 다른 어드민 기능에서도 UI 요소를 재사용할 수 있도록 설계했습니다.
