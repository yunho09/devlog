# 2026-07-22

## 요약
사용자가 경력을 단계별로 등록할 수 있는 경력 통합 등록 멀티 스텝 페이지와 등록 방식 선택 페이지를 퍼블리싱했습니다. 공통 UI 패키지(`packages/ui`)에 각 단계별 화면과 스타일을 모듈화하여 구현하고, 이를 어드민 및 사용자 웹 서비스의 라우터에 연동했습니다. UI 수정 과정을 거치며 버튼 비활성화 상태 제어 및 단일 행 선택 제약 조건을 반영했습니다.

## 변경 내용
- **등록 방식 선택 및 통합 등록 단계별 페이지 추가**: `RegistrationMethodSelector` 및 통합 등록 단계별 화면(안내, 업로드, 데이터 확인, 예시 확인, 완료) 구현.
- **공통 UI 모듈화**: `packages/ui` 내에 각 단계에 대응하는 컴포넌트(`IntegratedRegistrationNotice`, `IntegratedRegistrationUpload`, `IntegratedRegistrationConfirm`, `IntegratedRegistrationPreview`, `IntegratedRegistrationComplete`)와 스타일 파일 정의 및 내보내기(export) 처리.
- **웹 앱 라우터 연동**: `apps/admin-web` 및 `apps/user-web` 프로젝트의 라우터 구조에 새로 작성한 페이지들을 추가하여 서비스 경로 매핑.
- **상세 UI 동작 보완**: 특정 조건에서 버튼이 미리 비활성화되도록 수정하고, 테이블 내 행(row)의 복수 선택을 차단하는 제어 로직 적용.

## 의도
사용자가 복잡한 경력 입력 과정을 인지하기 쉽도록 단계별 가이드가 포함된 통합 등록 흐름을 시각적으로 제공하기 위함입니다. 공통 패키지(`packages/ui`)에 컴포넌트와 스타일을 함께 작성함으로써 어드민 웹과 사용자 웹에서 일관된 등록 UI를 효율적으로 공유하여 사용할 수 있도록 설계했습니다.
