## 트러블 슈팅
- **문제** → 민원인 로그인 후 발급 페이지에 진입할 때 존재하지 않는 `GET /api/certificates/self` API를 호출하여 401 Unauthorized 에러가 발생하고, 요청 본문 전송 시에도 명세에 없는 `certificateIds`를 포함하여 백엔드가 이를 무시하는 문제가 있었습니다.
- **해결** → 백엔드 컨트롤러와 Notion API 명세서를 검토하여 본인 발급은 POST 전용이며 GET 요청은 ADMIN/USER 전용 권한 필터링에 걸린다는 점을 파악했습니다. 이에 따라 프론트엔드에서 불필요한 GET 요청과 상태 재시도 로직을 완전히 걷어냈습니다. 요청 페이로드 구조 역시 `purpose`와 `otherMatters`만 전송하도록 스펙을 맞추고, 목록 조회 실패는 UI에 명확한 안내 문구를 노출하는 방식으로 우회 처리했습니다.
