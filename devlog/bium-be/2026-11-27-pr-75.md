## 요약
냉장고가 비공개로 전환된 후 작성자가 본인의 피드 댓글을 삭제할 수 없던 문제를 해결했습니다. 댓글 삭제 처리 시 권한 검증 순서를 변경하여, 비공개 상태인 냉장고라도 본인이 쓴 댓글은 냉장고 가시성 검사 없이 삭제할 수 있도록 수정했습니다. 타인의 댓글 삭제 시에는 기존의 권한 및 보안 검증 흐름(403/404)을 유지하도록 조치했습니다.

## 변경 내용
- `FeedCommentService.delete` 내 권한 검증 logic 순서 변경: `(commentId, fridgeId)`로 댓글을 먼저 조회하고 요청자가 작성자인 경우 냉장고 공개 여부와 상관없이 삭제 처리
- 본인 댓글이 아닌 경우 기존 검증 순서(냉장고 조회 가능 여부 -> 댓글 존재 확인 -> 냉장고 주인 여부)를 유지하도록 변경
- 타인의 댓글 삭제 시 접근할 수 없는 냉장고는 `FRIDGE_NOT_FOUND`(404), 멤버/공개 냉장고는 `FEED_COMMENT_DELETE_FORBIDDEN`(403) 응답 유지
- `FeedCommentServiceTest`에 비공개 전환 후 작성자 삭제, 주인 삭제, 외부인 404 및 멤버 403, 잘못된 냉장고 주소 요청 404 등 테스트 4건 추가

## 의도
냉장고 소유자가 상태를 비공개로 변경하더라도, 기존 댓글 작성자가 본인이 작성한 데이터에 대한 삭제권을 정상적으로 행사할 수 있도록 하기 위함입니다. 동시에 다른 사용자의 댓글 삭제 요청 시에는 보안 수준을 유지하여 존재 여부 탐색 공격 등을 방지하려 했습니다.
