# 2026-11-27

## 요약
장보기 항목의 이름을 수정하는 API(`PATCH /api/shopping-list-items/{itemId}/name`)를 새로 추가했습니다.
이름 수정 시 입력값 유효성 검증(1~50자, 공백 제거, 줄바꿈 불가)을 수행하며, 기존 체크 상태와 레시피 연결 정보는 유지한 채 변경된 이름으로 시세 정보를 다시 조회합니다.
해당 냉장고의 멤버만 수정 가능하도록 권한 검증을 적용하고 관련 컨트롤러 테스트를 함께 작성했습니다.

## 변경 내용
- `PATCH /api/shopping-list-items/{itemId}/name` 엔드포인트 및 `ShoppingListItemRenameRequest` DTO 추가
- 이름 수정 시 유효성 검증 규칙 적용 (앞뒤 공백 제거, 1~50자 제한, 줄바꿈/제어 문자 금지, 검증 실패 시 400 `INVALID_INPUT`)
- 장보기 항목 이름 변경 시 체크 여부, 담은 시각, 레시피 연결은 유지하고 시세 정보는 변경된 이름으로 재조회 로직 추가 (`ShoppingListItem`, `ShoppingListItemService`)
- 권한 검증 로직 적용 (타 냉장고 멤버 또는 존재하지 않는 항목 수정 시 404 `SHOPPING_LIST_ITEM_NOT_FOUND`)
- `ShoppingListItemControllerTest`에 성공 케이스(시세 재조회, 중복 이름 허용 등) 및 예외 케이스(유효성 실패, 권한 없음, 미인증) 테스트 추가

## 의도
기존 장보기 항목 체크 API(`PATCH /api/shopping-list-items/{itemId}`)는 `checked` 필드가 필수값이었기 때문에, 냉장고 재료 변경 API(`/position`) 패턴과 유사하게 항목 이름 변경 전용 엔드포인트를 분리하여 독립적인 수정이 가능하도록 개선하고자 했습니다.
