# 2026-11-27

## 요약
재료 도감 API 응답 DTO(`IngredientCatalogResponse`)에 기본 보관 위치(`defaultStorage`) 필드를 추가했습니다. DB 시드 데이터에는 기본 보관 위치 정보가 존재했으나 응답 DTO에 누락되어 프론트엔드에서 재료 종류와 무관하게 보관 위치가 항상 냉장실로 지정되던 문제를 해결했습니다. 또한, 컨트롤러 테스트를 추가하여 기본 재료와 사용자 추가 재료 각각에 대해 올바른 값이 반환되는지 검증했습니다.

## 변경 내용
- `IngredientCatalogResponse` DTO의 `category` 필드 다음에 `defaultStorage` (`FRIDGE`/`FREEZER`/`ROOM`) 필드 추가
- 기본 보관 위치가 없는 재료(사용자가 직접 추가한 재료)는 `null`을 반환하도록 처리
- `BasicIngredientCatalogControllerTest`에 도감 목록 조회 및 재료 추가 시 `defaultStorage` 필드 검증 로직 추가

## 의도
DB의 기본 도감 시드 데이터에는 `default_storage` 값이 저장되어 있었으나 API 응답 DTO에 해당 필드가 누락되어 있었습니다. 이로 인해 화면에서 "냉장고에 넣기" 기능 호출 시 재료의 특성과 상관없이 일률적으로 냉장실로 시작하던 버그를 수정하기 위함입니다.
