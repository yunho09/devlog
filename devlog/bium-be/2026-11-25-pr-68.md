# 2026-11-25

## 요약
냉장고 내 재료의 과거 구매 기록을 바탕으로 다음 구매 날짜와 주기를 자동 계산하는 API를 추가했습니다.
삭제되었거나 소진된 재료를 포함한 전체 구매 기록을 도감 또는 재료 이름 단위로 그룹화하여 평균 구매 주기를 산출합니다.
구매 기록이 1개만 존재하는 경우 기본 설정 주기를 활용하며, 주기를 계산할 수 없는 재료는 응답 대상에서 제외하도록 처리했습니다.

## 변경 내용
- `GET /api/fridges/{fridgeId}/purchase-schedule` 구매 일정 조회 API 추가 (냉장고 멤버 권한 필요).
- 삭제되거나 다 쓴 재료를 포함하여 `purchasedAt`이 존재하는 재료를 조회하는 `findAllPurchasedWithCatalogByFridgeId` 쿼리 구현.
- 구매 데이터 그룹핑 및 주기 계산 로직 구현 (`PurchaseScheduleService`):
  - 서로 다른 구매일이 2개 이상: `round((마지막 구매일 - 최초 구매일) / (구매일 수 - 1))` 식으로 주기 계산.
  - 서로 다른 구매일이 1개: 가장 최근 재료의 `purchaseCycleDays` 사용 (없으면 응답에서 제외).
  - 다음 구매일 = 마지막 구매일 + 계산된 주기 (다음 구매일 및 이름 순 정렬).
- 구매 일정 응답 규격 DTO 추가 (`PurchaseScheduleResponse`).
- 다양한 예외 및 계산 케이스(평균 주기 계산, 동일 일자 다수 구매, 삭제 데이터 포함, 권한 검증 등 16개) 테스트 추가.

## 의도
장보기 목록 화면에서 사용자가 언제 어떤 재료를 다시 구매해야 하는지 알려주는 달력 기능을 지원하기 위함입니다. 별도의 사용자 주기 입력 없이 이미 축적된 구매 기록 데이터를 활용하여 구매 주기를 자동 산출합니다.
