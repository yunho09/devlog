냉장고 멤버가 함께 쓰는 장보기 목록 API를 추가했습니다.
Sprint 2 "부족 재료 추천 및 장보기 목록"의 장보기 목록 부분입니다. 테이블(`shopping_list_items`)과 엔티티는 이미 있어서 스키마는 바뀌지 않습니다.

## 변경 사항
냉장고 멤버(주인·멤버)라면 누구나 같은 목록을 보고, 담고, 체크하고, 뺄 수 있습니다.

| API | 요청 | 응답 |
|---|---|---|
| `GET /api/fridges/{fridgeId}/shopping-list-items` | | 200 `{ items: [...] }` 안 산 것 먼저, 그 안에서 최근에 담은 순 |
| `POST /api/fridges/{fridgeId}/shopping-list-items` | `{ name }` 1~50자 | 201 항목 하나 |
| `PATCH /api/shopping-list-items/{itemId}` | `{ checked: boolean }` | 200 항목 하나 |
| `DELETE /api/shopping-list-items/{itemId}` | | 204 본문 없음 |

- 항목 모양: `{ id, name, checked, recipeId, recipeName, createdAt }`
  - `recipeId`·`recipeName`은 부족 재료 추천에서 담은 경우에만 있습니다 (#33). 직접 담은 재료는 null입니다.
- 목록을 볼 때 레시피 이름을 꺼내느라 쿼리가 따로 나가지 않게 레시피를 함께 불러옵니다
- 체크는 토글이 아니라 보낸 값으로 맞춥니다. 두 번 눌려도 결과가 같습니다
- 직접 담을 때는 앞뒤 공백을 빼고 담습니다
  - 줄바꿈·제어 문자는 냉장고 재료 이름과 같은 규칙으로 막습니다
  - 같은 이름을 다시 담아도 막지 않습니다
