## 요약
장보기 목록에 여러 재료를 한 번에 담을 수 있는 대량 추가 API(`POST /api/fridges/{fridgeId}/shopping-list-items/bulk`)를 추가했습니다. 요청 내 중복 항목이나 이미 미구매 상태로 목록에 존재하는 재료는 자동으로 건너뛰고 새로 담긴 항목만 결과로 반환하도록 구현했습니다. 한 번에 최대 30개까지 요청 가능하며, 동시성 이슈를 방지하기 위해 냉장고 및 미구매 항목 조회 시 비관적 잠금을 적용했습니다.

## 변경 내용
- `POST /api/fridges/{fridgeId}/shopping-list-items/bulk` 엔드포인트 추가 (바디: `{ "names": [...] }`)
- `ShoppingListItemBulkCreateRequest` DTO 추가 (항목당 1~50자, 공백 제거, 제어문자 금지, 1~30개 대량 요청 검증)
- 미구매(안 산) 동일 재료 및 요청 내 중복 재료 건너뛰기 로직 구현 (이미 구매한 재료는 다시 담기 허용)
- 동시 요청 시 중복 담기를 방지하기 위한 냉장고 행 및 미구매 항목 잠금 조회 적용
- 냉장고 멤버가 아닌 사용자 요청 시 404 `FRIDGE_NOT_FOUND` 예외 처리
- 컨트롤러 테스트(`ShoppingListItemControllerTest`) 추가: 중복 제거, 산 재료 다시 담기, 제약조건(빈 이름, 51자 초과, 31개 초과 등) 유효성 검증 테스트 작성
