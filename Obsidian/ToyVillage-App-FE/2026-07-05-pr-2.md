## 요약
ToyVillage-App-FE 프로젝트에 공지사항 리스트 화면과 라우터 구조를 신규 도입한 PR이다. 공지사항 상세, 운영안내, 자료실, 단체예약현황 등 세부 카테고리 페이지가 추가되었으며, 관련 UI 컴포넌트와 테마 토큰을 정비하였다. 목록, 생성, 상세 화면 간의 이동 경로가 라우터 구조에 맞게 정리되어 일관된 내비게이션을 제공한다.

## 변경 내용
- **공지사항 관련 신규 페이지 추가**: 상세 페이지(`NoticeDetailPage`), 운영안내 페이지(`NoticeGuidePage`), 자료실 페이지(`NoticeResourcesPage`), 단체예약현황 페이지(`NoticeReservationsPage`)를 신규 구현함.
- **라우터 및 내비게이션 정리**: `App.tsx`에서 신규 페이지들의 경로를 설정하고, 목록/생성/상세 화면 간의 이동 흐름이 올바르게 동작하도록 수정함.
- **테이블 및 탭 UI 보완**: 공지사항 테이블(`NoticeTable`)과 카테고리 탭(`CategoryTabs`)의 레이아웃 및 스타일을 개선하여 안정적인 화면 구성을 확보함.
- **공지 등록 버튼 개선**: `CreateNoticeButton`에 아이콘을 추가하고 컴포넌트 스타일을 고도화함.
- **테마 및 테스트 코드 업데이트**: 신규 디자인 토큰을 추가하고, 변경된 UI 명세에 맞춰 e2e 및 하네스 테스트 케이스를 갱신함.
